原界面式短剧的剧本解析、资产、分镜、成片页面和执行合同保持不变；不能导入原阶段页面并 Teleport 到画布冒充新交互。

## 已保留、未接入的代码

新增已接入部分（2026-11-08）：现有自由画布新增菜单中的“导入剧本／编辑剧本”打开共享 LivDialog 文稿弹窗。使用独立 script-document 接口保存并恢复完整原文与制作要求；保存成功才生成稳定文本节点。它不等于原截图中的资产提取、角色设计或短剧整链。

第二批接线：`useCanvasAssetExtraction.ts` 管理真实文本提取状态，`CanvasAssetExtractionControls.vue` 提供三类选择与一键提取。后端只返回有逐字出处的设定，成功后进入一个分类资产组；分类筛选仅控制显示。设定节点不冒充资产图片，风格设计、资产生图、分镜和成片仍待接通。文稿换版隔离迟到结果，读取失败不自动重提模型请求。

- `projection/dramaCanvasGraph.ts`：稳定业务身份、选版追溯及节点关系的纯映射，可作为新画布适配参考。不创建项目、不提交任务、不挂载独立 Vue Flow。
- `projection/dramaCanvasLayout.ts`：有限坐标校验，可供现有画布布局使用。
- 原独立画布组件、后端改动及回归样例存于 `docs/recovery/short-drama-boundary-20261108/`，仅供迁移审查，不是运行入口。

## 后续实施落点

1. 长文本粘贴提示和 TXT 附件复用当前输入器；原文与制作要求分开。剧本保存成功才向现有画布交付文本节点。
2. 独立会话制作合同保存画布阶段与固定来源，Agent 调用专项技能；复用既有提示词/解析模块，而不是改动原短剧页面或默认执行路径。
3. 节点内提供角色/场景/道具选择与一键提取；资产、分镜按真实成果进入现有画布，使用独立类型和分组适配。
   - 资产阶段使用一个资产分组框，内含角色、道具、场景分类及各自独立设定/图片节点；不以一张汇总图片代替可操作资产。
   - 分镜阶段使用分镜分组框，按集、场组织镜头；分镜文字、预演图、镜头视频分别保留真实状态和固定来源。
   - 最后输出成片节点，可播放、下载并追溯本次合成采用的镜头版本。没有实际成片时不显示完成。
   - 分组是画布组织容器，可整体移动、折叠；成员位置/归属变动不自动改写剧情来源、资产引用或执行顺序。节点工具负责真实制作操作。
4. 任务确认、风格选择和对话复用现有 Creation 组件；底部步骤提示来自真实执行阶段，不能写死假进度。
5. 画布后端适配使用独立命名空间，调用经过审查的业务能力；不能更改原短剧报价和执行含义。已有原项目必须显式选择，不隐式绑定/迁移。

以上是隔离设计和保留代码，不代表新画布剧本整链已经完成。每阶段必须记录真实页面操作与未通过项。
