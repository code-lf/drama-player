## Livliv简化方向

1. 选中两段成功视频后“合成短片”，自动带入顺序和真实时长，不要求理解成片目录、业务绑定和修订号。
2. 普通入口先显示预览、片段顺序、声音选择和合成。多个版本、历史、规格、毫秒裁切放高级编辑，能力保留。
3. 声音独立且可跳过：保留原声、无BGM或采用已有音乐；明确请求才核价生成音乐，不新增自动TTS。
4. 成片回画布，提供播放、下载成片、继续编辑；“继续”读取原结果，不重购。
5. 图片转视频仍走原模型报价确认；已有视频直切复用当前FFmpeg/LangGraph，不新建媒体引擎。
6. 简化路径不删除权限、固定版本、草稿修订、任务、账务和幂等防护。

## 现网验证边界

2026-11-01已在用户指定Oii工作区实测：通过本地页面下载两段原Seedance视频，再由空白画布右键“上传”的多文件选择器导入；两张独立视频卡实际解码显示。未上传私人业务资料，未点击旧对话的AI生成确认。

已有视频右键存在“AI剪辑”，点击会创建剪辑节点并打开编辑器：左侧剪辑Agent，中间大预览，右侧素材/滤镜/文字/详情，下方时间轴。默认带入当前一段；点击素材的“加入时间轴”将另一段追加后，总时长从00:04变为00:08。右上“导出”进入处理后恢复可用，素材区出现新视频候选；未核实导出文件下载及最终音轨，因此不把这一观察写为Oii成片文件验收。页面余额仍显示10 FREE，未遇采购报价，但这不是对其全部操作收费政策的保证。
