# 普通技能视频卡片 UI 整改

## 首帧与内容组间距纠正

- 用户反馈黑屏和工具距离过大后，主视频metadata就绪时定位真实0.1秒帧，不自动播放。浏览器未点击播放即出现画面，paused=true、readyState4。
- 视频、工具、说明、缩略图作为紧凑组布局，剩余空白放在组外。实际视频底部到工具顶部8px；1440×650产物条底部638px，390×844底部772px，未超出。
- 10项相关回归和Nuxt构建通过。截图`.data/video-group-first-frame-20261024.png`；临时视口已reset。

## 底部超出修复

- 真实浏览器复现：合成入口占33px，但外层为block，播放器另取整列100%高度；1440×900下产物条底部达到921px，被父容器裁掉。
- 改为入口与播放器纵向flex，播放器仅占剩余高度；播放器进一步按顶部、底部工具/说明、产物条、媒体内边距实测留空间，保持真实比例，预览上限560px。窗口变化由ResizeObserver重新计算，不依赖可能回退为视口高度的cqh。
- 最终浏览器：1440×900产物条底部888px；1440×650为638px；390×844为772px，均完整可见。对应视频高度512/262/412px，未裁切视频。临时视口已调用reset恢复。
- 9项相关测试与Nuxt构建通过；实际浏览器可见底部工具和缩略图。截图`.data/video-height-fixed-20261024.png`。没有提交Git、部署或新建生成任务。

范围：普通技能会话主播放器、视频方案选择卡、对话选项、合成预览和产物缩略图。不修改短剧、采购、报价、数量或费用授权。

- 主播放器读取文件真实宽高，切换作品重置比例；宽高不再同时铺满父容器。实测496×864的视频，桌面播放器约308×537，390px窄屏约260×453，保持真实比例且不裁切。
- 合成与批次结果预览延续按真实比例定宽的紧凑媒体卡，保留视频本身的黑边，不以界面裁切掩盖文件内容。
- 方案卡使用12px内边距，真实选中条目显示主题色边界与浅底，未选条目仍保留。方案、费用、操作的先后顺序不变。
- 批次确认／停止使用胶囊操作；长问答选项左对齐，完整内容可换行，保留原回答接口。
- 失效封面回退真实视频首帧，视频本身也失败才显示类型图标；不自动播放，不生成新素材。

验证：9项相关渲染／交互回归通过；Nuxt构建与真实浏览器验证分别记录，不把渲染测试当点击验收。播放器桌面／窄屏比例已实测；本轮没有发起付费生成。
