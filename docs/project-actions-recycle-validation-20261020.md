# 项目菜单与回收站交付

## 实现

- 侧栏菜单保留原生UPopover悬停，仅重命名、修改封面、收藏／取消收藏、删除项目四项，无继续对话和灰色占位。名称真实写回会话或短剧及主项目；封面沿用资料库上传、固定版本、签名预览及所有权校验，支持恢复默认封面。
- 收藏服务端排序在分页前执行。会话与短剧使用带类型的目录身份，避免误把会话编号发给短剧永久删除接口。
- 新表`creation_project_preferences`仅保存收藏、封面固定引用与回收站状态；删除不级联清除任务、对话或制作数据。新增本地迁移`20261020_0096_project_prefs`已应用，不回填或覆盖历史数据。
- 侧栏与我的项目删除均改为回收站操作；确认后提示“已移入回收站”，UApp Toast里的撤销和回收站为可点击动作，撤销调用真实恢复接口。`/dashboard-projects?view=trash`分页读取并恢复本人项目，有常驻回收站入口。
- 未增加永久删除或自动清理／保留天数；旧专业短剧删除接口保留底层能力，但统一项目目录不再调用。
