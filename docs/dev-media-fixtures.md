## 当前实现

- 文本仍走原 Alibaba / Deep Agents 配置，未修改全局 `PROVIDER_RUN_MODE`。
- 替换商品/自由创作及技能调用中的图片、视频采购执行，并支持纯音乐 Mock；不改短剧。
- 原权限、素材版本校验、模型能力校验、方案核价、用户确认、队列、批次回填、画布和合成服务继续使用。
- 新任务保存 `config_json.dev_media_fixture`，结果保存 `mock: true`，完成状态注明“非本次模型生成”。图片适配器返回原标准 `task_id/image_url/provider/model` 合同；视频由原 Worker 接回 `results_json`，不伪造第三方账单或采购 ID。
- 样本报价为 **0 积分**；不调用媒体供应商、不新增媒体消费或退款流水。文字调用仍可能产生原有真实费用，媒体存储仍使用原存储服务。
- 默认关闭、明确账号白名单、生产启动拒绝开启。没有匹配文件或文件损坏就报错，绝不自动转真实采购。

## 开启与切回真实

API 仓库 `.env` 中配置以下独立选项；不要改动全局 `PROVIDER_RUN_MODE=live`：

```dotenv
DEV_MEDIA_FIXTURES_ENABLED=true
DEV_MEDIA_FIXTURES_OWNERS=测试账号UUID
DEV_MEDIA_FIXTURES_MANIFEST=.codex-runtime/media-fixtures/manifest.json
```

修改后需重新启动 API **及消费商品图片/视频任务的 Worker**，保证两端读取同一环境。当前代码默认关闭；本轮冒烟仅在独立进程临时启用，没有切换正在运行的服务。

切回真实：设置 `DEV_MEDIA_FIXTURES_ENABLED=false` 并重启 API / Worker。新报价重新走真实价格及确认；旧 Mock 任务仍按冻结样本恢复，旧真实任务不会被开关迁移成 Mock。线上禁止执行旧 Mock 任务。不要把本机样本库或启用配置复制到线上。

如果开启/关闭发生在报价与确认之间，应重新核价；原金额和当前后端不一致时拒绝提交，不能沿用旧费用授权。
