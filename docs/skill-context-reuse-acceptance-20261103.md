# 技能上下文复用与按需工具验收（2026-11-03）

## 本轮修改

- 沿用已有 Deep Agents、LangGraph、原运行记录与权限服务，未增加 Agent 框架或基础组件。
- 首次真实读取成功后，将技能固定快照保存到原运行私有字段 `_canvas_skill_snapshot`。以本人、运行、技能键、版本、指导正文和文本资源摘要隔离；续答命中后直接把固定指导交模型，不执行 `read_skill`，不新增开场或“沿用技能指导”操作卡。快照不从浏览器或模型返回接受，不随公开运行接口返回。
- 只复用技能指导，不复用权限、动态模型目录、任务进度、报价、费用许可。新技能/版本/资源内容/运行身份变化必须重新读取；旧运行没有可信快照时首次读取建立，不能仅凭历史完成图标推断已缓存。
- 新需求不再强制查询空链路进度。涉及明确父运行的续作仍先从原业务服务读取进度，未知受理或未完成批次不再规划新采购。补资料、读取方法资源、查真实模型目录和整理方案仍由模型按工具描述选择，不强制经过完整列表。
- 同一问答运行的补充答案沿用快照；新开运行不是同一个缓存作用域，不做全账号共享缓存。每轮模型仍需要得到固定指导上下文，这不是声称模型跨请求永久记忆或不再消耗指导输入 token。

## 保留边界

模型仍可能选择不必要的可用工具，框架本身不保证永不冗余；本轮解决确定性重复读取和初始空进度前置，没有以隐藏真实调用或删除失败来美化记录。供应商断线、延迟和生成内容质量需分别验收，不能由一次问答成功推断全部创作链无缺陷。
