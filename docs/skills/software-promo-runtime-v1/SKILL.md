# 软件产品宣传片：标准运行技能 v1

这是用于验证平台创作链路的人工核对稿，不是已完成全链路验收的证明。用于软件、SaaS或App宣传片，不将虚构UI当作软件真实功能。

## 输入与澄清

需要软件名称、目标受众、已确认功能及其操作方式、核心痛点、CTA，以及是否有真实截图或录屏。复用对话中已有答案，只询问关键缺项。没有真实素材时使用明确标注的概念视觉，不捏造功能、效果数字或试用权益。

总时长、画幅、输出目标未明确时询问；已明确时不重复问。制作40秒、60秒等指整体叙事长度，不自动等同每次模型调用时长。模型、规格和素材最终以当前运行目录及用户选择为准。

## 先策划，再制作

1. 读取本技能及`software_promo_method.md`，核对已知资料。用户只要文稿时直接输出完整文字，不建立媒体任务。
2. 给出一份可审核的时间轴，包含时间范围、完整口播、画面、运镜、首尾衔接及声音建议。时间段之和等于用户目标时长；停顿包含在段落时间内，不重复相加。口播字数只是预估预算，不能称已完成真实配音对齐。
3. 为各段提供完整独立的提示词；画面中逐项区分真实素材、概念示意和待用户确认内容。若只有一个卖点，不编造另外两个。
4. 用户要求继续制作后，按照真实模型目录拟定片段计划及素材来源。叙事段可以拆成若干符合规格的片段，但不得从镜头数自动认定收费任务数量。展示真实计划及报价，沿平台确认入口提交。
   - 先核对已授权素材：有适用图片则复用；缺真实产品/UI/Logo/人物素材时，让用户上传或从资料库选择，不用AI补造为真实素材。未确定来源时只询问缺项，确认采用概念视觉后才规划AI生成。
   - 如需生图准备视频素材，每张只对应一个镜头的单幅连续画面，描述主体、环境、构图、光线与一致性。不把整片时间轴、口播、镜头说明或多格分镜板画入素材；明确要求或已确认技能环节需要故事板时可以制作审核说明图。
   - 用户确认全部镜头各制作一张时，组织为一份独立素材批次：逐镜头标题、独立提示词、素材来源及规格，统一核算总价、一次确认后调度，不要求逐张重复发送。画布保留计划到各镜头的追溯连线，真实结果回到对应节点；成功项保留。图片确认不等于视频费用授权，视频阶段另行核价。
5. 成功片段保留，失败或未知受理项只沿原任务读取/对账与显式重试处理。不得自动重购或把“已提交”当作“生成完成”。
6. 片段完成后，让用户选择仅交片段或继续成片，以及保留原声、配音和BGM的意愿。只调用运行时真实开放的声音与合成能力；未接通的阶段准确说明，不能凭文档声称混音完成。

## 交付与修改

文字阶段交付完整可编辑文稿、分镜和提示词；媒体阶段返回实际任务结果与原来源。修改仅涉及用户指定部分，保留已确认事实、其它条目与原作品；修改影响报价时重新核价。不能用“已准备好”替代实际正文或结果。
