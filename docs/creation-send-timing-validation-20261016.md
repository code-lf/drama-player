- 真实点击发送复现：旧会话入口为图片，云草稿技能为自由创作，接口返回 400「技能与当前入口不兼容」。前端曾把业务错误统一显示为连接中断，造成误判。选择自由创作及发送前统一修复入口组合，其他技能不扩大兼容范围；业务错误显示实际说明。
