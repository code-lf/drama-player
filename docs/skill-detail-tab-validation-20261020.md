# 技能详情、瀑布流与 Tab 示例

## 已实现

- 首页技能卡点击先预览；技能中心复用同一套自然比例瀑布流与 UModal 详情。
- 卡片左下显示技能名及黑色渐变，悬停／键盘聚焦展开简介和右下试用按钮；触屏保留可见试用入口。
- 详情标题在左，右侧提供分享菜单、收藏、试一试及关闭；公开图片／视频在前，四段指南在后。视频带控制条，不自动播放。
- 新增版本配置 `public_guide`：技能简介、适用场景、使用方法、输出内容、Tab 示例。后台独立编辑，不读取内部执行 Markdown。旧客户端漏传不清空；历史版本保持不变。
- 旧技能使用已有公开简介及输入要求兼容；未配适用场景明确提示未配置，不杜撰输出数量、价格或能力。
- 试用只重查上架状态并选技能，不自动填充示例、提交或扣费。空框按正向 Tab 才通过现有模板分段器填入字段；保留中文输入法、Shift+Tab 和已有草稿。模板仍直接填充。
- 停靠时的预览前滚动位置独立记录，详情关闭完成后再恢复并展开；不在焦点陷阱中强行切焦点，不用延时猜测。
- 收藏沿用真实接口，分享只复制平台公开预览链接；私人技能不提供公开分享，不携带草稿、会话、素材或费用许可。

## 验证结果

- 前端全量测试：267 项通过，包括真实组件编译、四段公开字段、字段语法、Tab 防覆盖、旧关闭／分享重复打开、停靠恢复方法。
- API：公开指南与首页展示共 5 项通过。嵌套事务回滚验证新版本、旧客户端保留及公开响应白名单，未改实际运营内容。
- 后台全量测试：28 项通过（其中技能专项 11 项）；后台生产构建通过。
- 用户端生产构建通过。三个仓库差异检查通过，仅有原有行尾规范化提示。
- 本地 API 在确认没有正在进行的文字规划任务后重启加载配置字段，不部署。

## 浏览器结果与边界

- 1920px 五列；1440px 五列；390px 两列、无页面水平溢出，手机详情宽 358px、左右各 16px。
- 技能中心读取实际目录后显示 18 张共享卡片，不再套旧等高卡片。
- 公开分享链接仅打开详情，不自动选技能；关闭后目录刷新不会反复重新打开。
- 游客 Tab 实测只填入示例，商品和背景字段可编辑；测试后清空游客输入，没有发送生成任务。
- 视频技能详情实际资源 readyState=4，controls=true、autoplay=false、paused=true；分享菜单项存在，Esc 可关闭详情。
- 浏览器普通定位点击会先将目标居中滚动；改用保持当前焦点的键盘事件复测后，停靠小条宽 435px，预览和试用前后 scrollTop 均为 543，详情关闭后输入框为 `is-docked`、宽 800px，没有跳回顶部。截图 `.codex-runtime/skill-dock-expanded-final.png`。
- 真实账户收藏保存、剪贴板复制及后台保存未作人工端到端验收。

## 后续产品判断（本轮不删除入口）

- 案例已有“公开案例 → 有效关联模板 → 技能准备”链路。没有关联模板时不可从成片推断配方；建议将有配方的入口标为“复刻同款”，无配方的案例只做欣赏，并提供明确的同类技能浏览入口。展示媒体不能自动成为参考素材。
- 当前图片创作与自由创作共用输入、模型、生成和修改能力，主要区别是入口引导、推荐技能与案例。若不做专业图片工作区，建议将图片创作收为自由创作里的快捷入口；保留原路由、草稿和底层能力，不直接删除功能。
