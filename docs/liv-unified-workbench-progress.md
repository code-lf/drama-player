# Liv 统一创作改造实施与验收记录

更新日期：2026-10-14。本记录描述当前实现与证据，不将构建、模拟文字响应或离线合成当成供应商全链路成功。

## 追加：参考界面尺寸与资产改造

- 读取 Oii 页面可见元素尺寸：标题 24px／30px，技能名称 14px，试用按钮 12px／32px，侧栏菜单 14px／36px、图标 16px。本站已按相近比例调整，并在内嵌浏览器窄面板验证三列卡片。
- 主题强调色集中为 `--liv-accent: #409EFF`，普通按钮保持灰底；不使用 Oii 品牌色及品牌素材。
- 技能分类单行：我的技能、全部、自媒体、广告营销、游戏、短漫剧、周边设计；个人视图分我创建的／我收藏的。旧分类兼容映射，不覆盖历史技能版本。
- 自由入口增加音频模式，使用已有 Suno 业务引擎和签名报价上下文；音乐专用技能仍限定音乐入口。已验证同页切换音频与音乐参数显示，未提交收费生成。
- 新资产页与创作浮层共用我的资产／演员库／音色库／回收站；读取真实私人和平台素材，支持固定版本、上传、预览、归档恢复。原文档片段与版本管理入口保留。
- 音色库第一版是授权音色录音资产及真实文件预听，不是声音克隆，也没有伪造语言、适用场景或配音员目录。当前账号没有音色录音，播放功能尚需有真实文件后做浏览器验收。
- 本轮 API 专项回归 101 项通过；前端结构回归 13 项通过。后续界面微调仍以浏览器实际尺寸为准。

## 已接入的实现

- 独立技能中心 `/dashboard-skills`、侧栏技能菜单，平台／个人／收藏目录、详情、私有创建、编辑、复制、受控导入导出及归档。
- 后台技能配置、不可变版本、入口范围、推荐技能、模型策略与参数限制；个人技能查看／停用、文字规划额度与运营配置。
- 图片与视频有效候选目录及选模浮层；签名技能上下文在准备、报价和工作台正式提交时参与校验。音乐工作台正式提交也冻结操作输入、歌词与后台引擎版本。
- 推荐技能与模板分离，音乐技能限定音乐入口；模板引用真实固定素材版本、缩略图预览／替换、占位提示动画和独立滚动布局。
- 自动报价、点击提交、快照失效、变价再次点击、幂等编号恢复；移除额外费用确认框。409 冲突清除旧报价，网络失败保留原提交编号。
- 对话规划、聊天内询问与回答、取消、待回答和导演草稿刷新恢复；恢复等待目录加载，避免默认生图参数覆盖原视频配置。
- 同会话图片转视频确认与固定图片版本；结果类型与当前输入技能分开。
- MV 三种配方、音频权限与真实时长校验、歌词文字规划、既有短剧项目关联与原歌曲主音轨合成。当前节奏安排明确标为估算。
- 账号成片水印偏好、标准导出应用、统一创作者协议草稿及既有协议校验、后台飞书帮助和二维码设置。统一协议未发布，未替用户同意。

## 尚需收口，不能宣称全计划完成

- 导演／MV 的逐镜头技能模型策略，需要继续传播到既有短剧分镜报价和正式任务；当前直接图片／视频策略校验不能替代这项验收。
- MV 目前按选定音频片段总时长进行合成对齐，仍需接入已有歌词时间轴、可编辑镜头节奏与分镜关联；不能宣称精确卡点已完成。
- 对话中自动区分现成歌词与创作意图，以及规划问题与多阶段工具状态的完整运行联调，仍需补充覆盖。
- 实际供应商歌词→剧本→资产→分镜→镜头视频→成片全链路未执行；必须另行明确媒体生成预算。当前离线 FFmpeg 和模拟文字响应只证明局部能力。
- 创作者协议草稿需后台审核发布；飞书地址、真实二维码需运营配置。未配置入口保持禁用，不替用 Oii 资源。
- 后台实机编辑、所有窄屏与中文输入、重复点击／响应丢失浏览器故障注入，仍需继续专项验收。
