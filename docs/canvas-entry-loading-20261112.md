# 首页进入画布加载与重复状态修复

## 定位

原会话恢复在读到真实会话之后，仍等待运行历史、参考素材与完整能力目录，才在 finally 中撤掉整页加载。目录仅做一次本机未登录计时约1.3秒、响应约706KB，不能据此宣称它单独解释用户遇到的数分钟；开发模式冷编译与其他请求耗时仍需分开测量。

## 本次调整

- 真实会话读取并核权成功即可挂载正文与现有Agent状态，其余恢复继续进行。
- 能力目录恢复期间loading与busy保护保留，云草稿尚不可生效，不以默认规格进入报价或生成。失败结束加载并保留真实错误。
- 方案增量预览接替同一次generate_response的进行中行，只展示「正在整理」。失败、停止及修正保留真实提示，未确认属性仍有读屏说明。

## 证据与边界

- 加载及过程组件与构建依赖边界专项45项通过，包含预览去重、错误状态与先显示会话的代码边界。不是完整接口耗时模拟。
- localhost:3000实际从首页发送两次只读测试，不采购媒体。修改后第二次观察：点击约744ms仍在会话读取；约6.14秒观察到正文、画布及正常终答（助手用时4秒）。这个数是采样观察上界，不是精确首帧或P95，也不是复杂图片链路耗时保证。
- 截图另存本目录evidence/canvas-entry-loading-20261112。本轮没有复现持续数分钟，不能宣称所有慢请求原因都已排除；若仍发生应继续针对当次请求和开发服务器日志追踪。
