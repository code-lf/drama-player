# 技能页与首页共享输入框

## 结构与行为

- 首页及技能页均只挂载一个 CreationStudio，内部只有一个 CreationComposer；技能页采用 skillsPage 模式，保留完整上传、模板、参数、草稿与现有生成流程，不复制提交逻辑。
- 技能页目录沿用共享瀑布流及详情，分类18px／700、选中800；增加真实推荐标记筛选，保留全部、我的技能、收藏、搜索、导入与私有技能编辑。
- 底部默认收起为435px胶囊，选定技能显示技能名称；展开最大800px。切换显示不卸载编辑器、不改变草稿。首页停靠区同步沿用同一显示。
- 卡片和详情的“试一试”均在本页选能力并展开；详情等待关闭完成后交接。跨入口保留原作用域草稿并在有内容时确认，恢复目标草稿后才选能力，不自动填示例或生成。
- 数字人口播仍为专用工具入口，读取真实可用性，未配置明确禁用。
