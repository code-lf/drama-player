# 创作工作台收口记录（2026-10-15）

## 本轮落地

- 会话统一时间线：媒体消息、助手回复与当前问题放进同一滚动区，按关联运行去重、按创建时间排序；离开会话清理临时状态与订阅，异步回写检查会话和请求代次。
- 输入框恢复完整静态提示，编辑区 96–220px；Enter 发送、Shift+Enter 换行，输入法及 @ 候选优先。推荐回答只填入草稿，不自动发送。
- 普通聊天使用显式 chat 模式，服务端不能签发媒体执行许可。已选技能仍先判断意图，普通发送不预先创建图片修改引用。报价在采用方案时才执行。
- 公开正文流：供应商实际正文前缀转成持久化快照，附递增序号；不转发推理字段。修正正文更新导致 SSE 重建的限流问题；后续回答订阅按最小调用序号隔离上一轮状态。
- 技能版本支持声明式字段及后台编辑预览；问题支持推荐、多选、素材入口、自由回答和上一步。修订号阻止旧标签页回答过期问题，新增素材在服务端重新验证归属。
- 音乐恢复双卡排版：封面、信息、进度和控制放在左卡，大字号歌词放在右卡。沉浸与工作台共用一个音频节点；当前句使用独立白色令牌，不随主题反转成深色。
- 尺寸选择使用触发器锚定的 UPopover；图片工具栏与作品组成居中内容组。修正工作区菜单悬停后点击立即关闭的问题。
- 普通输入不再频繁请求媒体报价；普通入口不加载整页音乐目录，结果请求去重、只刷新未完成任务、隐藏页面降频，失败轮询退避。界面错误不展示内部 Fetch 请求 URL。
- 案例授权扩展到固定的图片／视频／音乐输出，旧导演成片授权保持兼容；保留撤销、发布依据和版本绑定。已应用本机数据库增量迁移 `20261015_0091_case_sources`。
