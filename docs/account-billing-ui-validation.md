## 后续修正：悬停边界与Logo菜单精简

- 根据最新反馈，左上角只保留首页／我的项目／资料库／技能四项，移除账单组和展开导航。下文原交付的Logo账单入口记录已被此规则覆盖，个人中心账单入口保留。
- 根因：Nuxt菜单内容包含多根和传送节点，content参数中的鼠标移入事件不能可靠透传，按钮离开后的计时仍在运行。统一以document捕获的pointerover／pointerout和真实按钮、菜单节点判断边界，进入取消旧计时，真正离开延迟关闭；触屏不介入，卸载移除监听。
- 前端214项测试通过，新增跨触发器／菜单／子节点／外部／空目标／触屏边界回归，并调整旧“展开导航必须出现”的断言。
- 移除按钮与菜单间的悬空间隙；延迟关闭前再次检查实际悬停状态，菜单内部点击不再被全局监听误判为外点。
- 真实浏览器：左侧仅四项，点击“我的项目”正常跳转；右侧移入菜单后保持展开，点击“发票管理”正常到达对应路由。最终生产构建通过。未触发支付、生成或其他收费操作，未提交Git、未部署。
