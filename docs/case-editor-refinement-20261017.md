# 创作案例后台优化验证

## 本轮实现

- 两个 Tab：案例内容、展示设置；正文滚动，保存草稿区固定，品牌靛紫与 Ant Design 组件统一。
- 平台上传／已授权作品互斥。选择作品自动识别媒体类型；名称使用已有案例标题，无标题时使用媒体类型及授权时间，不读取私人需求。
- 封面与真实图片／视频／音频并排预览，不自动播放，失败明确占位。封面 16:9，上传大小沿用真实接口：图片 5MB、音视频 50MB。
- 授权列表补充案例标题和已登记封面编号／预览，仅管理端可读；撤销授权仍立即移出候选。查询限定当前百条授权及相关封面，不扫描私人任务或整库正文。
- 展示入口、可选模板、排序和发布记录归展示设置。失效／不兼容模板显式处理，不静默清空。三个目录独立处理失败并保留旧数据。
- 保存与发布分离：保存必回草稿；发布仍确认公开展示权与依据，由服务端检查媒体可访问及真实授权，不绕过原规则。

## 验证结果

- API `tests/test_creation_cases.py`：10 项通过。使用外层回滚事务，覆盖授权、撤销、草稿／发布／下架、模板与鉴权；没有执行真实上传或收费媒体生成。
- 后台 `node --test apps/web-antd/tests/*.test.mjs`：19 项通过，其中新增案例编辑器运行／结构测试 6 项。执行真实 setup 并编译模板，网络与基础组件隔离，不等于浏览器验收。
- 后台类型检查、生产构建与差异空白检查通过。

## 发布弹窗排版修复

- 用户截图暴露 Ant Checkbox 根 label 被普通字段 grid 样式影响，勾选与文字拆行；改用独立确认容器，并显式保持 inline-flex 和首行对齐。
- 公开内容改摘要分组，移除段落默认底部留白；依据三行输入、必填标识和审核说明。未确认或空依据禁用发布，原服务端校验不变。
- 后台回归增加对应结构保护；依旧不将结构测试或构建视为真实浏览器视觉验收。
