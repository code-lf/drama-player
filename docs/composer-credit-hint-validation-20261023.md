# 输入框积分随当前参数刷新验收

## 修复

- 原提示每次只读取模型目录最低档起价，因此质量、清晰度、比例、数量和时长变化不会选择当前计价条件。
- 现在复用图片／视频业务请求编译器及服务端 credit-preview，只读 `hint_only` 不创建素材快照，不调用LLM、不创建生成任务、不扣积分。素材权限和真实用量校验保留。
- 300ms 防抖，参数变化立刻清空旧数字；乱序响应、账号变化和卸载使旧响应失效。失败、无效报价及未登录时隐藏，不用最低价兜底。
- 正式报价的“点”与原“积分”文案均可解析，合法零值保留。确认卡继续控制实际生成和锁价。
- 图片正式预估改为共用生成字段编译，避免遗漏风格、场景及海报文字造成Token用量不一致。
- Seedance旧目录空比例与执行器语义不一致，导致前端置空比例、接口422。缺省比例只从已有已核准执行协议补齐，非空后台白名单不扩大，未知模型不猜测。

## 自动测试与边界

- 前端20项：数字解析、快速连续切换、乱序返回、失败／无效预算、零值、卸载、参数与确认卡原有交互。
- 后端36项：只读预算与正式报价共用计算和素材校验、无快照副作用、图片Token预算实际目录矩阵（隔离事务回滚）、比例缺省、工作台画幅与请求Schema一致、原清晰度及素材时长约束。
- Nuxt构建通过（依赖包已有警告不作为功能证明）；真实浏览器验收单独记录。
- 未进行付费生成、任务扣费或跨账号登录端到端测试，不将预算验证冒充生成验收。
