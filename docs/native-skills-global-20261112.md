## 原六项失败

1. 一项流程测试仍以 SQLite 验证只允许 PostgreSQL 的正式入口，现改用已有隔离 PostgreSQL 测试环境，生产数据库限制未取消。
2. 五项技能试用测试替换的是旧规划器，实际新引擎不会调用它。现替换供应商模型边界，保留真实 Deep Agents、技能读取、业务合同与数据库路径。
3. 试用断言更新为逐项媒体计划；不恢复从用户文字解析数量、时长的旧逻辑。方案准备不等于提交或授权。

## 页面发现并修复的附加问题

浏览器补答只要求复述时，旧规则因“已经读取助理”强制再交结构化方案，造成两次复述后错误收尾。现在只读终答可直接成为 `Reply`，不解析为任务；已进入真实规格选择、问题卡提交或固定分镜生产时仍保留结构化门禁。

失败记录未删除、未伪改为成功。修复后新运行在同一测试会话完成问题卡→补答→正常文字终态，未准备媒体任务或授权。页面证据：
