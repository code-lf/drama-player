# 普通短片与音轨链路验收（2026-10-29）

## 本版交付边界

目标是需求整理、片段计划、逐条核价、确认生成、选择声音、合成、返回成片；不是文档声称调用了工具就算交付。内容段落不等同采购片段，须按实际模型可用规格拆分，保留总数量。

首版声音模型：片段原声 + 一条已有旁白 + 一条已有BGM。旁白与BGM分别由用户选择，默认不添加；允许调整入点、裁切和音量。不自动采购、拉伸、循环、精确对口型、压制字幕或自动降低BGM。独立AI配音任务尚未接通，不能把口播文案或音色预览当作配音结果。
