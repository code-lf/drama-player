# 短剧边界恢复与画布分组要求

## 原因与处理

此前将“复用原短剧业务能力”错误实施为“原短剧页面新增画布视图并嵌入原阶段组件”。用户要求的是现有自由画布的新制作链，不是改造原界面式链路。

已撤回原短剧页面、四个阶段组件、相关前端合同，以及 API 原短剧路由/服务/Worker 的本轮改动。原始补丁及实验测试保存在同目录 recovery/short-drama-boundary-20261108，未清理用户历史项目、任务或账务。

保留的纯节点投影和布局校验位于 features/creation/drama/projection；媒体样本辅助代码在 API 的 app/services/creation_drama 下隔离，未注册运行入口。旧独立画布组件仅留参考，不再挂载。

## 新画布交付边界

现有自由画布新增剧本节点，依次连接资产分组框、分镜分组框、成片节点。资产框分类展示角色、道具、场景；分镜按集、场组织。组内成员保留独立身份、操作与真实状态，组整体移动/折叠只改变布局。

共用现有对话和确认组件，底部显示真实执行步骤。原短剧提示词与后端能力经独立适配复用，原界面式流程不修改、不嵌入。新画布整链尚未交付。
