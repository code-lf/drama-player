# 自由画布剧本第一阶段接线

## 本次实现

现有 CreationAgentCanvas 新增“导入剧本／编辑剧本”，共享 LivDialog 设置弹窗，支持直接粘贴或读取 UTF-8 TXT。保存完整原文与独立制作要求，成功后创建稳定剧本节点；节点可移动、查看/编辑，刷新恢复相同身份。保存错误保留输入，修订冲突不覆盖。

文稿保存在既有 CreationWorkspaceDraft 的独立 canvas-script 命名空间，新增 creation_drama 路由与服务；不创建原短剧项目，不调用原解析或生成服务。读取不写入，保存不采购，未新增表或 Agent 框架。
