日期：2026-11-07。最新状态：正式入口已替换四区壳，真实平台保存/撤销、视频预览与BGM解码波形已在浏览器验证；**剪辑Agent工具、全量拖动恢复及用户导出门槛仍未完成，不是首版整体交付**。下方早期批次内容保留为阶段记录，以文末续报为准。

## 实际实现

- 锁定npm `fablecut@1.18.0` 完整性与原始源码指纹，保留MIT及机械导入脚本、两处40ms补丁。停止并行接入WebCut，不运行原Node/MCP或引入示例资源。
- 前端候选合同及真实上游分割适配：顺序、图片时长、视频源裁切、原声音量及音轨独立源区间/入点/循环。整组克隆验证，失败不污染输入；仅视觉缩短时明确同组截短音轨，新加超长音乐不能静默裁短。
- 保存队列串行、原请求号重试、409保留本地、卸载拒绝迟到响应。AI不能穿过未完成手动保存。成功回执后才移动最多100组内存撤销历史，撤销同样生成白名单操作，不透传整稿覆盖。
- 隔离通信协议：指定窗口＋opaque origin＋128位channel＋版本/类型/请求号校验；拒绝重复、超大和未知消息。**只有协议模块，尚无实际iframe、媒体地址通道或UI。** 没有导出、采购、任意URL或脚本透传。
- API新增剪辑Schema、命令接口及固定素材解析器，字段有中文说明，拒绝可定位。保存复用原成片草稿的plan与修订，不另建项目；实际编辑才幂等建稿，命令回执固定到原请求。真实素材解码在锁外，事务内重新核权、CAS及保存探测收据；不把缓存命中当作当前权限成功。
- 第三版草稿通过原成片jobs接口冻结快照及派发，不增加另一套导出任务。FFmpeg支持静态图片、视频混排、原声音量和显式音乐循环；旧合同及指纹含义不改。**前端只有服务与保存控制器接线，尚无可点击的新工作台导出入口。**
- 旧表单不能覆盖第三版稿；新旧任务的历史计数、画幅与画布连线兼容读取，避免全局任务列表因缺少旧clips字段崩溃。保存失败、冲突及卸载后的迟到响应不覆盖本地候选。

## 已验证证据

### 第三批：原生浏览器实验接入

- 新增开发专用`/editing-probe`（生产返回404），原HTML/CSS/20个客户端脚本从固定tar归档生成并记SHA256。无Node/MCP服务、原网络导入、文件监听或项目持久化；sandbox不带allow-same-origin，CSP禁止网络/Worker/子页，媒体由父壳传字节后创建隔离blob。
- 原生保存、连接、同步及撤销入口通过AST替换；键盘/高级按钮与鼠标事件在捕获层限制。仅允许预览、播放、缩放与主轨拖动/边缘裁切，候选编译为平台白名单命令，不发送原生整稿。
- 真实Edge浏览器发现并修正：开发路由未更新造成客户端404；Worker受CSP阻断后标尺离屏canvas无法重新设尺寸；Vue代理不可structuredClone；离线applyProject不自动解码图片；重复传输相同媒体导致旧blob失效。
- Edge真实页面：仓库已有样图预览成功；拖图片右边缘由4秒变3秒，父页返回一项内存编辑；再添加第二段，拖到首位，稳定DOM顺序为probe_2→probe_1，连续主轨不保留间隙。截图见[evidence/fablecut-native-20261107/sorted-images.png](evidence/fablecut-native-20261107/sorted-images.png)。本页不写业务稿、不采购、不导出。
- 仍未验证：原生双音轨/循环、私人视频解码、真实波形、平台保存与子页联动、完整四区UI及Agent。原生投影目前只有视觉轨，不得把已有音轨草稿投影为完整可试听成片。函数序列化和生产压缩的兼容性仍须在正式懒加载入口前解决。
