# 统一技能框架实施记录（2026-10-23）

## 本批实际完成

- API 增加 LangGraph、PostgreSQL checkpoint、连接池依赖并更新 uv.lock。
- 新增受控阶段字段、问题组与答案校验；拒绝未知字段、非法选项、重复编号和损坏素材引用结构。
- 新增 LangGraph 整组收集节点：暂停时返回问题组、已知答案与修订号，整组提交后恢复，不按字段调用模型。
- 新增局部修订函数，保留其他答案，冲突拒绝覆盖。
- 提供 PostgreSQL 持久化器资源入口；不在读取时自动 setup 建表，不改变现有数据。
- 图节点无模型调用、媒体提交或扣费代码；恢复不具备执行许可。

## 验证边界

- 隔离测试使用内存 checkpointer，覆盖暂停恢复、已知答案保留、线程隔离、只读恢复、非法输入和修订冲突。
- 尚未进行 PostgreSQL 实库重启恢复测试；内存测试不代表进程重启后仍能恢复。
- 已增加会话阶段创建／读取／局部保存／整组提交接口；答案保存于既有会话运行 JSON 中，带行锁、账号权限、修订和幂等收据。此接口持久化不是 LangGraph PostgreSQL checkpoint，不能混为同一完成项。
- 目前只允许未调用模型的新轮次显式开启阶段；整组提交本身不调用模型，之后由原 advance 接口领取文字分析。旧链路默认不变。
- 尚未接入阶段卡页面、自由输入合并或启用任何技能的新编排路径。
- 未执行浏览器验收、构建或付费生成，不启动 Worker、不迁移历史数据、不提交或部署。
