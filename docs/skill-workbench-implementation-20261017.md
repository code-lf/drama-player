# 技能管理与自由音乐工作台实施记录

## 已实施

- 保留已认可的工作台铺满布局：390px 默认聊天列、320～560px 拖动范围、8px 分隔条、12px 外边距。有任务或作品显示双栏，纯对话正文最大 760px；1024px 以下切换对话／作品，聊天折叠不重建播放器。
- 顶部导航默认收起，完整侧栏仅点击打开，1440px 以下用 USlideover。最近会话用 UPopover，200ms 悬停打开、250ms 离开关闭，复用主页十条分页、更多与重命名；操作期间保持，换号／路由／卸载清理延迟和迟到请求。悬停打开不主动夺走编辑器焦点。
- 后台平台技能／用户技能／运行记录／全局设置按需读取。编辑分技能内容／素材／发布设置，Markdown 编辑和安全文本预览优先，高级规则保留旧字段；默认参数取真实模型能力，版本自动递增，取消不落库，保存失败留草稿。
- 平台技能固定引用已发布平台素材版本，不借用用户个人素材。总计最多十二项，准备和提交重新校验；下架先查询当前技能依赖并明确确认，动态显示素材健康状态，保留历史版本及作品，不增加物理删除。
- 创作目录新增 capabilities，助手区分平台能力和技能执行范围。自由创作保留自由技能生成音乐，单引擎按钮仍能打开并切换媒体；参考音频走真实参考操作和授权，不静默丢附件，不附加 MV。

## 未验收与边界

- 真实浏览器访问受当前工具限制，尚未验收 2560／1920／1440／1024 和移动端实际菜单定位、焦点、拖动、弹窗滚动与播放连续性。静态检查、类型及构建不能替代这些验收。
- 未调用真实音乐或其他收费生成，未扣用户积分；没有修改正式技能配置、下架真实素材或批量改写历史数据。
- `pnpm theme:check` 仍报告 `pages/index.vue` 既有硬编码主题样式；本轮不扩大到首页视觉重构，不标记整体主题检查通过。
- 本地 API 首次重新加载前检查近期无进行中的文字规划；已重启本地 8000 API，健康检查 200，未动生成 worker。随后补充了助手系统能力说明和当前技能能力交集；最终重载请求被执行策略拒绝，没有通过拆分命令或其他方式绕过。服务仍运行，但最终后端变更需再重启本地 API 才全部生效。不提交 Git、不部署。

## 主要接口兼容

- `/creation/catalog` 和 `/creation/public-catalog` 保留 skill_models、music_operations，新增 capabilities（platform／current／allowed_targets）。
- SkillConfig.references 默认空；个人技能兼容原顶层引用。未知旧字段由服务端旧版本合并保留，请求新增未知执行字段仍被拒绝。
- `/admin/library/{id}/dependencies` 查询当前平台技能依赖；发布状态请求新增 confirm_dependencies，涉及依赖的下架未确认返回 409。
