# 工作区启动优化与验收（2026-11-04）

## 已确认的问题

- 工作区采用 CSR，旧 HTML 的 Nuxt 挂载根节点为空，脚本启动前只能看到全局渐变背景。
- 公共素材配置插件等待接口完成后才允许客户端挂载；普通项目目录还会等待旧短剧配置、风格、项目和账户流水。
- 页面静态引入未打开的媒体工作区和账户弹窗；同时预加载约 9.7 MB 的两套完整字体。

## 本轮改动

- 使用 Nuxt 自带 `spaLoadingTemplate`，直接在 HTML 内输出项目／首页／会话公开占位，不读取私人信息。Vue 启动后由对应组件接管。
- 公共素材配置在 CSR 异步读取，五秒超时且不重试；SSR 仍等待配置并复用注入值。CSR 配置迟到时可能先使用本地图片地址，暂未消除这类双地址请求。
- 普通工作区不等待旧短剧初始化和账单流水；账户异步补齐，流水打开积分弹层时读取。能力和采购继续使用所属服务及原权限、报价流程。
- 重工作区和未打开的弹窗按需加载，创作模块下载期间继续显示对应骨架。
- 取消整套字体强制预加载；实际需要的字体仍通过原 `@font-face` 加载，不表示完全消除了字体流量。

## 第二轮：导航不能等待内容区（同日）

- 第一轮异步组件仍使用 Vue 默认 `suspensible: true`，在 NuxtPage 下可能让整页外壳等组件下载；已统一收口为 `defineWorkspaceComponent`，强制 `suspensible: false`，仅内容位置等待。
- 继续拆分 CreationStudio 内未展示的画布、剪辑、视频工作台、技能中心及专项媒体工具。仅把最外层工作台异步化不足以减轻首页依赖。
- 资料库入口原先每次挂载都从 `false` 开始，能力返回前整个入口不存在。改为公共三态共享值，未知保留入口、明确禁用才隐藏，真实接口权限不变。
- 新增真实 Vue 内存渲染测试：外层 Suspense 下模块一直未完成时，导航按钮仍已挂载、可切换，旧模块晚到不覆盖新页。启动与目录相关 20 / 20 通过，构建通过。
- 浏览器资料库→工作台→项目连续切换通过：进入工作台的首个观察中，侧栏和资料库入口已经显示，内容仍为局部骨架；随后项目页在资料读取中保留菜单。一次工作台点击加状态读取约 302ms，包含自动化往返，不是浏览器纯渲染指标，也不是冷缓存首屏保证。
- 全量测试为 994 / 996，另两项旧静态断言仍要求 `workspaceToast.add` 与页面内“重试加载会话”，与此前已修改的统一顶部通知实现不一致；本轮不为满足旧断言恢复旧 UI。需在通知专项更新其行为验收，不宣称全量通过。
