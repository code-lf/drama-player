# 技能制造内容验收口径

同题需求：帮我创建一个用于生成60s软件产品宣传视频的可复用文案策划技能，包含口播、分镜和视频提示词。

参考用户提供的Oii结果，不将外站模型、工具名称、价格或效果承诺当作本站能力。

| 对照项 | 合格交付 | 不算通过 |
|---|---|---|
| 输入定义 | 软件、受众、痛点、已确认功能、CTA、素材及规格，说明来源与缺失处理 | 未提供录屏却声称资料完整 |
| 阶段组织 | 输入、具体动作、可编辑交付、检查及后续阶段 | 只有生成剧本等目录 |
| 口播与分镜 | 每段台词、动作运镜、首尾衔接对应同一时间轴 | 只承诺后续会生成 |
| 独立提示词 | 每段或每版本完整可填变量正文 | 只有变量或要素清单 |
| 时间预算 | 单一服务端时间表，扣停顿后核算，填变量后重计 | 两表冲突或写满10秒又声称另留停顿 |
| 规格模型 | 已确认值优先，未指定用变量，推荐与绑定分开 | 变量中藏默认比例清晰度 |
| 事实权益 | 只使用已确认功能、效果、权益及CTA | 默认提升百分比、优惠或官方正品 |
| 资源工具 | 引用真实资源和已注册业务入口 | 虚构资源及active_step/write_script调用 |
| 执行边界 | 内容段落与采购片段分开，按真实模型核价 | 总时长直接固定采购次数或自动重购 |

英文输入字段可用作稳定变量，但须说明中文含义；英文工具名只有实际注册且服务端校验才表示可调用，文档不能授予权限。

## 自动门禁和人工验收

内部_timeline与_prompt_templates只编译同一Markdown，不另建执行或账务状态。自动验证时间、停顿、模板编号及覆盖、变量和默认规格，不能证明文案有说服力或画面可生成。

人工仍检查模板是否独立可用、缺失输入分支、素材依据、夸大语义、品类方法及示例一致性。ready、新连接恢复、自动测试均不能代替内容验收。
