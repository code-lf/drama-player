# 短剧入口及案例播放优化

- 隐藏短剧输入框“模板”按钮，不删除后台模板或修改强制关联规则；其他入口模板按钮保留。
- 案例封面统一16:9，取消旧144px高度上限导致的比例截断，媒体子层占满卡片。真实浏览器4张封面均约276.4×155.47。
- 案例播放复用UModal，仅保留无障碍标题；可视标题与说明移除，复刻／全屏／关闭为画面右上方纯图标按钮及Tooltip。动态读取视频或图片尺寸，横竖屏均按原比例适应视口，不通过object-fit:cover裁切播放画面。
- 第一条原成片自带编码黑边：1280×720，多帧cropdetect最大内容范围412×720（x432,y0）。生成独立展示副本，原任务与原片保持不变；其余3条未检测到一致大黑边，不裁切。4条封面更新为原视频1秒处真实画面。API脚本scripts/refresh_drama_case_frames.py默认预检、--apply执行；所有案例再次走原模板、媒体及授权发布校验并记录审计。
- 当前关联模板本质是新整理的公开提示词配方和允许编辑的参数，不是原任务的完整剧本／资产／分镜快照，也不是自由画布。短剧复刻进入“描述想法”草稿，沿原剧本确认、资产、分镜、成片流程执行，不保证还原原作品。
