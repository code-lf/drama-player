# 电商／广告顶部入口与技能关联分类验收

## 本轮交付

- 顶部五个用途 Tab：自由创作、短剧、电商、广告、音乐·MV；commerce保持电商编码，新增marketing作为广告编码。
- 电商：推荐、主图与详情、商品展示、内容种草、口播带货。广告：推荐、品牌广告、信息流广告、达人营销、节日促销。
- 用途入口共享原编辑器、素材权限、模型、报价确认及执行器；前后端草稿、会话、发布Schema和校验接受marketing。
- 一个技能的home_showcase.entry_categories关联多个入口和分类，不复制身份。旧category仍供未迁移版本兼容；显式清空关联会隐藏对应首页展示，不删除技能。
- 首页快捷推荐最多8个；广告技能保留旧commerce许可兼容已有会话，但没有电商展示关联时不混进电商首页。
- 后台技能编辑支持两组多选分类；模板、案例入口同步支持广告。旧后台漏传新字段保留现有关联，明确清空才移除；版本冲突拒绝覆盖。
