# 技能填入与提示词撤销验收

- 最新交互覆盖旧的“只选技能不填文字”：快捷使用、首页试一试、技能目录试一试填入公开示例；不读取内部执行文档，不发送或生成。
- 去掉“已选择技能，可按Tab…”成功Toast；失败、下架与读取错误仍提示。
- 编辑区显示可点击的“Ctrl+Z 恢复原提示词”，按后进先出逐次恢复原文与字段；最多100次有效替换，仅内存保存。相同文字及字段不重复记录；跨账号、入口、会话、执行过程清空。
- 撤销只处理提示词，不回滚模型、技能、报价或执行许可；引用仅保留当前仍有效的版本，不复活已移除素材。使用保留现有素材。
- 手动编辑时保留浏览器原生Ctrl+Z，精确回到技能填入快照时才撤销技能替换；Shift+Ctrl+Z、输入法组合不拦截。
- 快捷名称与使用按钮置于同一UPopover触发区域；鼠标按下使用不抢编辑器焦点，键盘与鼠标均走相同选用链路。
