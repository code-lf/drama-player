# GPT Image 2 图片Token预算首版

## 范围与当前状态

- 首版支持 ToAPIs `gpt-image-2-official` 无参考图、非营销套图的参数预算。VIP 与其他型号不套用。
- 正式报价服务与后台模拟复用同一引擎。后台增加提示词、真实档位、比例、张数和启用前预览。
- 当前模型仍保持原固定售价：只执行了真实后台模拟和启用预览，没有确认启用。
- 原因：参考图输入尚缺本型号可核实的Token估算规则，直接替换会影响已有图生图能力。营销套图逐张提示词未冻结、其他短剧调用未传完整提示词时，也不能冒充已支持。

## 核实来源与规则

- [OpenAI 图像生成文档及输出用量计算器](https://developers.openai.com/api/docs/guides/image-generation#gpt-image-25-and-gpt-image-2-output-tokens)
- [所核对的官方计算器实现](https://developers.openai.com/_astro/GptImageTokenCalculator.react.CyMnjJpk.js)
- [ToAPIs 官方渠道尺寸表](https://github.com/toapis/docs/blob/main/docs/cn/api-reference/images/gpt-image-2/official.mdx)

规则版本 `gpt-image-2-text-v1-20261022`：质量网格边为16／48／96，按画幅求短边并进行银行家舍入，再对 `网格面积 × (2,000,000 + 像素面积) / 4,000,000` 向上取整。尺寸仅取供应商实际对照表，不插值；4K不支持方图。

文本采用最终编译提示词UTF-8字节数上界作为预算估计，并非声称精确分词；不额外乘风险系数，不预先假定缓存命中。每张独立提交n=1，文本与输出用量都按张数累计。不要把本规则当作精确账单，也不能套GPT Image 1参考图规则。

## 采购成本与用户报价

五类采购单价与汇率冻结到报价快照，分别核算文本输入／缓存文本／图片输入／缓存图片／图片输出。按总预算成本和有效毛利率计算固定积分，仅对最终总价向上取整；保留已生效固定售价覆盖。提交任务及历史订单不按后续改价重算，不追加扣点。

完成后图片任务使用返回分项用量核对实际采购成本，按批次和图片序号幂等保存到原台账JSON。缺少、损坏或无法分类的用量为pending，不能记成零成本。实际成本写入异常不把已成功的生成误报失败；待核对原因留在调用日志。采购核对不是供应商最终发票对账，不保证实际毛利等于目标毛利。
