# 手机号统一登录与注册（2026-10-20）

## 实现

- 工作台弹窗复用 LivDialog settings dark，独立登录页共用同一表单。标题“注册 / 登录”居中24px／700，下方显示“新人福利”，不承诺固定赠分，不新增奖励或会员功能。
- 仅保留密码登录／短信登录两种方式，短信入口由真实认证能力接口决定可用性。移除注册分支、昵称输入和“记住我”；不更改已有登录态保存策略，不设置默认密码。
- 现有短信登录接口在验证码通过后为新手机号建号；数据库手机号唯一约束与保存点处理并发插入冲突。停用用户不恢复，错误验证码不建号。协议先校验，成功后按 sms_register／sms_login 留痕，不调用积分赠送链。
- 底部文案为“继续即表示您同意 用户协议 与 隐私政策。”，只有用户点击提交才传递当前展示的强制协议编码。协议读取失败阻止提交并提供重试，阅读或切换登录方式不会签署。
- `/auth-terms` 只读汇总当前强制条款原文及其版本，包括既有创作条款；隐私单列 `/legal/privacy_policy`。不复制第三方法律文本、不修改发布状态、不删除支付和上传的独立许可。
