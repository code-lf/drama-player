# 视频工作台整改与创作画布一期评估

## 当前页面整改

- 提示词入口改称“当前提示词”，编辑区使用可用宽度，播放器尽量利用扣除控件后的剩余高度；保持文件真实比例，不为填满空间裁切或拉伸。
- 合计收为一行“合计 N 点数”，删除额外解释行和24px放大字号；视频完成结果复用图片的`CreationResultCard`，保留真实静态首帧、任务身份和右侧查看行为。
- 未生成改稿原先只查询新方案批次，导致误入空白工作台。现在沿服务端记录的`revision_parent`在同会话内查找真实成功原片，明确显示“原视频 · 尚未重新生成”。新结果优先、失败或未知任务不作为成功来源；跨会话和循环引用拒绝。
- 无原片的新方案直接进入提示词编辑，不展示没有素材却可点击的截帧／引用按钮；保存不收费，生成仍核价确认。

## 可公开的一期范围建议

1. **只读作品关系图**：在当前会话右侧显示商品素材、方案、视频、合成结果节点；固定来源连线、缩放、平移、适应内容。左侧继续对话，右下角收拢真实任务列表；没有任务不显示虚假进度。
2. **受控编辑与保存**：点击节点用同一个停靠编辑器读取当前提示词，保存新增修订；拖动位置、备注和连线单独保存。素材引用边与装饰连线分开，跨类型／跨会话／循环依赖校验，删除连线不删除作品。
3. **按选择执行**：节点生成仍进入原逐项报价、批次确认与任务服务；任务ID、状态和结果只引用业务记录，图存布局与关系，不另建执行权威。修改单节点只重新制作对应条目，保留未改成功视频；合成复用现有服务。
4. **开放门槛**：账号／会话权限、刷新与冲突恢复、双击幂等、断线与Worker恢复、费用授权、桌面／窄屏和20～50节点性能验证。付费测试另按具体模型与预算授权，不自动消耗旧任务。

一期不包含：短剧重构、任意脚本节点、完整NLE时间线、多人协作、自由插件执行、自动发布／投流。自由画线不是任意执行许可。

难度为中等偏高。交互原型可较快完成，但公开可用必须包含权限、恢复、收费防重与真实浏览器验收；按一名熟悉项目的全栈开发者建议预留3～4周工程量，原型核对后再细化，不作为固定交付承诺。67项技能逐项专业化另行验收。

本轮只实施当前工作台修复并形成评估，不启用旧画布路由，不安装新的编辑器、不提交Git或部署。
