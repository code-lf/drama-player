# Livliv 节点式创作前端说明（首期）

## 1. 目标与范围

- 目标：先完成 `livliv` 前端可演示闭环，核心链路为「脚本生成 -> 分镜生成 -> 创意编排 -> 批量视频操作」。
- 范围：仅前端交互与样式，接口使用 Mock/占位调用；真实后端与阿里 API 后续接入。
- 平台：PC 优先；移动端仅保留浏览能力，不提供完整画布编辑。

## 2. 我对 LibTV 工作流的理解

## 2.1 核心设计思想（节点驱动）
- 每个创作阶段都是一个节点：文本、图片、视频、音频、脚本、分镜等。
- 节点之间通过连线传递上下文（提示词、参考图、脚本结构、分镜参数）。
- 画布不是单页表单，而是「可视化工作流编排器」，便于拆分和复用链路。

## 2.2 脚本到分镜的关键闭环
- 用户在脚本节点输入需求，触发大模型产出结构化脚本（镜头粒度）。
- 在脚本节点内进行二次操作：
  - `重新生成`：基于补充文本重写脚本。
  - `生成分镜`：进入分镜参数配置并提交任务。
- 分镜结果以卡片集合承载，每张卡片对应一个镜头并可批量进入视频阶段。

## 2.3 创意视图的批处理逻辑
- 对镜头卡片进行批量选择后，统一设置模型、分辨率、比例、摄像机参数。
- 支持批量动作：重新生成、批量生成视频、解组、批量下载。
- 排版模式是工作效率工具：宫格/水平/垂直，服务不同审片和整理场景。

## 4. 当前前端实现映射（已落地）

## 4.1 脚本节点配置区
- 顶部双按钮：
  - `重新生成`
  - `生成分镜`
- `重新生成`模式：
  - 文本输入框（补充需求）
  - 可切换文本模型
  - 提交按钮（前端占位日志）
- `生成分镜`模式：
  - 风格选择（风格库弹窗）
  - 模型选择（下拉面板）
  - 分辨率/比例选择（面板）
  - 摄像机选择（弹窗）
  - 已选脚本计数（`x/x`）
  - 开始生成（前端占位日志 + 状态切换）

## 4.2 分镜工作区（脚本视图 / 创意视图）
- 视图切换：脚本视图（表格）与创意视图（卡片）。
- 工作区支持拖动与全屏切换。
- 创意视图顶部批处理工具条：
  - 宫格排列 / 水平排列 / 垂直排列
  - 重新生成
  - 批量生成视频
  - 解组
  - 批量下载
- 卡片支持选择，底部参数条同步展示模型、分辨率、摄像机、已选数量。

## 4.3 状态管理
- 新增 `storyboard studio store` 管理：
  - 脚本工作模式（rewrite/storyboard）
  - 创意排列模式（grid/horizontal/vertical）
  - 分镜参数（风格/模型/分辨率/摄像机）
  - 选中镜头与总镜头计数

## 5. 下一步开发计划（前端 P0/P1）

## 5.1 P0（优先立即做）
- 节点类型卡片完整化：文本、图片、视频、视频合成、音频、添加资源统一组件壳和差异化内容区。
- 创意卡片详情操作补齐：标记、聚焦、重试、单卡下载、单卡生成视频。
- 参数条联动完善：风格/模型/分辨率/摄像机全部支持回填与可视状态。
- 批量操作状态反馈：进行中、成功、失败三态与错误占位。

## 5.2 P1（随后）
- 分镜拖拽排序（卡片重排）与布局持久化。
- 生成任务进度条与失败重试队列。
- 风格库筛选、搜索、最近使用与收藏状态。
- 画布快捷键体系扩展（撤销/重做/多选/框选）。

## 6. 后端对接预留（不改页面层）

- 页面只调 `service`，不直接请求。
- 真实 API 切换仅改 `api adapter/runtime config`。
- 关键接口预留：
  - 脚本重生
  - 分镜生成任务创建
  - 分镜结果查询/轮询
  - 批量视频任务创建与进度查询
