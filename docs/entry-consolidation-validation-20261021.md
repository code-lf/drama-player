# 图片入口收敛、短剧页签与广告技能拆分验收

## 实现范围

- 图片创作仅从用途导航／初次用途选择隐藏，不新增快捷入口。`image` 定义、深链、草稿和执行能力保留；平台商品主图／海报设计开放 `free` 入口。
- 短剧三种原输入方式使用同一个 UTabs 顶部连体页签，不引入参考站点的视频转换／画布功能；文件限制、费用确认与原流程不变。
- 模板字段使用专用高对比浅靛紫令牌，保留安全文本分段与可编辑字段。品牌实心色仍为 #4F46E5。
- 显式选择“广告短片”走直接模型流程；“广告创意短剧”绑定原 `ad` 执行器，仅开放导演流程，并有独立简介、公开指南和示例。移除广告输入框里的模式按钮，故事模式不变。
- 旧 `ad` 的导演流程不收窄，历史版本／模板不重写。只有明确新选技能才应用选择策略，恢复和模板仍用原参数。

## 配置与历史

API 仓库提供 `python -m scripts.consolidate_creation_entries` 只读预检；应用须显式传 `--apply --backup 新文件路径`。预检、版本快照、并发核对、单事务新增版本，已有自建广告技能不覆盖。
