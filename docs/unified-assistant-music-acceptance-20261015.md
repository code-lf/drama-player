# 统一创作助手与娱乐音乐工作台：实施与验收

日期：2026-10-15。范围：用户端、API、运营后台。未提交 Git、未部署、未清队列、未新建收费媒体验收任务。

## 已实施

- 普通发送先进入 Liv 助手；持久化普通回复、单个澄清问题、最多四个可编辑建议选项及方案卡。显式短剧入口沿用原流程。
- 助手独立模型配置默认 qwen3.7-plus；只使用后台已启用文字模型和既有凭据工厂。文字调用使用平台额度与调用审计，不写用户扣点流水。
- 技能文档随不可变版本发布。17 个非导演技能有独立中文专业细则；精确匹配旧系统模板才自动追加文档版本，人工修改内容不覆盖。运营端可编辑、预览及保存新版本。
- 上下文包含本人固定素材、选中结果、媒体历史及已持久化助手对话。普通评价不会直接创建歌曲；跨媒体先采用方案、再核对参数报价。
- 会话独立确认规则、三类免确认、默认 10 秒冷静期及默认 100 点阈值。未知报价不自动执行，整组报价判断阈值。
- 执行许可绑定方案、固定工具入参、规则修订和幂等请求号；修改草稿或规则撤销许可，刷新不重放自动提交。
- SSE 只传持久化状态与最终卡片，不输出思考过程；断线重连不重放模型或生成请求，等待时释放数据库连接。
- 排队取消与 Worker 领取使用行锁互斥，复用原退款引用。供应商处理中的任务不伪装为可暂停；停止文字流程不代表停止其他媒体任务。
- 停止入口使用独立有限计数，仍执行黑名单、登录校验及限流失败拒绝，避免只读轮询耗尽默认桶后无法停止。
- 音乐真实进度与旧阶段估算分开；保留供应商快照和原始值，迟到低进度不倒退覆盖，显示来源与更新时间。
- 受权下载按本人音乐任务及曲目序号读取真实音频，复用 HTTPS / DNS / 跳转校验下载器，不接受任意 URL。
- 移除重复音乐页签和普通用户专业工具入口，底层与历史保留。写歌通过参数切换纯音乐，固定引擎显示信息标签。
- MV 来源收进输入框，保留真实授权勾选；已完成歌曲复用歌词，无歌词走视觉创意，不自动转写或宣称精准卡点。
- 会话与独立音乐页共用单音频播放器；真实时间轴歌词高亮定位，无时间轴静态展示，沉浸切换保留播放位置。本地试听不上传、不创建任务。

## 已有验证证据

- API 相关回归 72 项通过，含独立 SQLite 权限、默认确认规则、修订冲突、自动阈值、冷静期、许可指纹、同请求幂等、停止、来源曲目、无歌词 MV、真实进度及停止限流。
- 前端结构与纯逻辑回归 62 项通过。静态结构断言不视为浏览器功能验证。
- 用户端与运营后台生产构建通过；用户端仍有依赖的构建警告，不能将构建视为全量类型检查。
- 全量类型检查仍有短剧资产、分镜等范围外错误；创作区及共享音乐播放器定向检查无错误。
- 使用 computer-use 技能在真实浏览器验证已有歌曲播放、歌词定位高亮、单 audio、沉浸切换保留位置及 Esc、受权音频下载。
- 两次真实歌曲听后感只产生普通回复；核对测试时段新增音乐任务 0、新增扣点流水 0。第二次文字调用审计正常成功，扣点 0。
- 标准会话设置弹窗实测宽 560px，开关为 40×22px。桌面与窄屏检查不产生横向溢出；发现并修正播放按钮被底部工具遮挡。
- 修复旧半透明样式及停止限流冲突后，真实浏览器停止文字响应成功，服务端返回取消，草稿保留；按钮计算色为 rgb(79,70,229)，方块为白色。
- 窄屏 390×844 作品视图复测：播放按钮底部约 644.5px，小于画布可视底部 683px，无横向溢出。截图保存到 output/workspace-v2-design/。
- 本地 3000 / 3002 / 8000 与 Redis 已复用启动。三个 Worker 分别订阅 celery / storyboard / render，线程池并发分别为 4 / 2 / 1；保留单实例 Beat。启动核验时三个队列均为 0，没有主动新增收费验收任务。

## 仍不能宣称全部验收完成

1. 尚未通过新建收费媒体任务验收自动执行到真实供应商、扣点及退款整链路；默认禁止新增收费验收任务。
2. 多标签同时执行、取消与 Worker 真正并发竞争目前有行锁实现与隔离回归，尚未进行 PostgreSQL 压力竞争实测。
3. 三种 MV 来源完整付费制作、跨媒体完整成片与供应商连续进度尚未做收费浏览器验收。离线 FFmpeg 合成和无歌词快照测试不等于供应商全流程通过。
4. 第一次文字实测遇到事件流占用数据库连接，普通回复已保存但审计完成写回失败。已修复连接释放并以第二次成功审计复测；仅对本次验收遗留的一条审计按持久化回复对账收尾，显式标记供应商元数据缺失，不补造 token 数量、不重放供应商调用、不改账务。
5. 供应商处理中是否可取消必须由真实适配器能力决定；当前不宣称支持中途停止，更不支持原任务暂停续跑。

因此，功能代码已大幅落地，但本计划不能标记为“全部真实功能验收通过”。
