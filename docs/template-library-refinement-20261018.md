# 模板、公共素材与原创案例补齐

## 本轮实现

- 模板裂图根因是预览地址硬编码 localhost:3000，而本地用户端未启动。改用平台站点媒体登记映射，不依赖后台或用户端端口；六张图片、两段 MP4 共八项已登记，资源采用内容摘要路径，不覆盖历史文件。
- 模板主表分类／状态筛选，列宽及横向滚动；编辑分为模板内容、示例媒体、展示设置，保留参数与固定引用高级 JSON，预览仅文本节点，不执行 HTML。媒体上传改用 Ant Upload。
- 公共库分公共素材／用途分类／容量设置三个 Tab，默认列表；用途／类型／状态在服务端分页前筛选。表格预览、固定版本、横排操作、失败重试和迟到响应保护；容量单位 MB／GB，保存仍传原字节契约。
- 案例列表补搜索、分类与状态筛选、明确列宽；发布人保留在只读发布记录，避免主表过密。
- 已真实新建“小熊猫的松饼危机 · 3D 卡通喜剧”，案例编号 `a1d893f7-ef35-486d-b71a-cf7249972173`，分类 cartoon-3d，入口自由创作／图片创作，封面和媒体均为最终原创小熊猫图。当前为草稿，未自动发布；原有案例状态不变。媒体已转存平台并登记，不只停留在本地风格预设。
