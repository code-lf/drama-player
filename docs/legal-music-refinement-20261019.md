# 协议阅读页与音乐参数修复

## 变更

- 侧栏协议入口改为 `/creator-agreement`，原 `/legal/:code` 共用主题化阅读组件；只展示已发布正文，不发布合并草稿，不新增独家代理条款。
- 登录确认集合由服务端统一返回：服务、隐私和当前创作条款。前端合并阅读链接，实际同意仍记录各原始版本；原账号不自动补签。缺失当前创作条款时返回登录确认，不再弹四段重复长文，不自动重放生成。
- 支付与素材上传独立许可保持原边界，继续显式确认；阅读页面不会调用同意接口。
- 音乐结果为同一次任务返回的两首同名候选，音频地址不同；聊天卡增加真实曲名和序号，不删除第二首。
- 核对旧任务发现 instrumental=false，但生成描述要求纯音乐，结果歌词仅为 Instrumental 占位。新增非自定义歌词模式的冲突阻断，不篡改歌词、不修改历史作品、不自动重新收费生成。
- 音乐参数浮层改为 320px，“歌曲”显示名改为“歌词”。尺寸样式针对 UPopover 传送后的真实节点，不依赖工作台祖先。

## 验证边界

- API 相关 45 项检查通过；前端相关 17 项检查通过，包含模板编译与展示配置回归。
- 浏览器检查协议页：零对话框、零复选框，深色背景与浅色正文；登录链接合并为服务／隐私／创作者协议，未代用户同意。
- 浏览器音乐弹层实测宽 320px、类型按钮约 137px、文字 14px，卡片显示第 1 首与第 2 首；未提交真实媒体生成。
- 保留已有未提交变更，不提交、不部署、不批量改写协议或用户同意记录。
