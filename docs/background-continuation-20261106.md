# 总目标与异步媒体接续（2026-11-06）

## 本轮实现

- 复用 Deep Agents、创作链、现有 Celery/Redis 和最终任务确认服务，没有增加框架或第二份媒体状态。
- `generate_response.continue_after_tasks` 由模型结合完整目标判断。媒体仅是阶段交付时返回 true；单图已经满足目标时 false。不扫描用户句子猜测阶段，不硬编码图片→视频顺序。
- 模型决定为 true 才保存接续安排。后台核对本轮真实任务终态及成果，使用稳定请求号创建一轮免费规划，结果通知独立标记 runtime，不伪造用户“继续”。历史未记录接续决定的运行不自动启用。
- 新轮沿用完整总目标、前序问答及真实进度，强制保留最终媒体确认。后台只调用规划，不能确认、采购或导出；合成仍走原有受控准备及用户确认。
- 同一用户锁、稳定编号与执行锁防重复。新消息取代旧接续；停止暂停后续规划并取消未执行自动子轮，已提交媒体及成果不撤销，重复停止幂等。
- 通用 Worker 每20秒检查；周期链由 Redis 短租约去重，数据库失败不丢下一次扫描。状态不明、成功但未有结果文件不触发后续；失败终态交给模型判断，不自动重购。自动接续最多16轮，达到边界须人工检查，不继续后台循环。
- 页面每5秒只读取当前轮和后端子编号，不通过轮询启动规划，不重刷全历史素材地址；自动轮不显示重复用户气泡。
