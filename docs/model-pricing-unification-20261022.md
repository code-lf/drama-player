# 模型规格、调价和报价改造验收记录

## 已实现

- 采购真实单位与用户报价规则分离；ToAPIs 媒体默认策略提供60%毛利、总积分一次向上取整的预览迁移入口。
- 图片、视频报价模拟统一默认折叠；顶部展示策略摘要并提供策略弹窗；停用档位默认隐藏并标明历史用途。
- 模型支持连续范围（含步长）和固定时长；新增价格档位、后台模拟、用户滑条及服务端校验消费同一规格。
- 档位级采购锁定和售价锁定保留历史人工配置；支持目录候选差异、选中解锁重预览、强制重建完整预览。
- 人工采购成本与策略经预览后事务保存；保存后重读列表、详情及版本，清除旧模拟，读取失败明确提示。
- 用户模型目录提供零售参考价格，不返回采购成本与目标毛利；确认前按参数重新核价，确认后不追补。
- 每日计划只在管理员确认合格模型的统一策略预览后启用，缺目录或预算的模型列出原因。

## 验证结果

- 后端相关回归：298项通过（含隔离事务中的确认、锁定、强制重建、60%迁移与计划启用测试）。
- 后台交互测试：19项通过；后台类型检查及生产构建通过。
- 用户端时长、参数和比例测试：10项通过；用户端生产构建通过。
- 真实后台浏览器：验证Grok固定时长配置及新增档位6/10秒选择、默认折叠、顶部策略弹窗、当前模型刷新保留、统一60%及每日计划预览。
- 三仓库差异空白检查通过；保留原有未提交修改。
