# Livliv 用户端 UI 规范

- 案例播放器底栏及按钮改为中性灰色，真实播放状态驱动播放/暂停图标，图标切换重建防止缓存旧形态。用户打开案例默认有声音，浏览器禁止有声自动播放时等待点击，不以静音绕过；用户手动静音选择在本播放器保留。此条覆盖旧静音自动播放规则，列表悬停预览仍静音。首次引导沿用左侧自由创作、右侧四张封面卡布局，分别显示短剧、电商、广告、音乐·MV，与顶部用途一致。

- 支付收银台沿用深色设置弹窗，金额统一两位小数、36px亮色展示，期限紧随其后；订单号可换行，官方收银台说明与自动到账说明各只出现一次。主次操作独立分组、间隔12px，按钮尺寸不变；noopener打开返回空值不能直接判定为被浏览器拦截。支付状态仍仅由服务端确认。

- 分类吸顶补背景仅在标题实际抵达sticky边界后显示；普通排版、向上返回以及离开吸顶边界时隐藏，禁止遮盖标题上方快捷技能的第二行。

- 首页分类吸顶时抵消正文顶部大内边距，与顶部用途导航之间只留8px；背景遮挡保留，未吸顶时不挪动原内容排版。

- 首页底部收起输入条高56px，展开编辑器不变；顶部输入框离开实际可视区域立即出现，不再等待案例／技能分类吸顶。分类吸顶背景覆盖滚动容器顶部内边距，与顶部用途导航之间不允许露出卡片形成断层。

- 技能“试一试”可带入后台example_refs登记的已发布固定示例图，来源是独立示例图字段而非封面。保留用户素材，替换上一次试用示例，支持移除和撤销，不保存个人素材、不自动生成或授权费用。固定执行references保持独立，不得在执行时补回用户移除的示例。示例已有明确风格时清除继承标签；与用户手动风格冲突先确认。

- 游客选择已公开模型后也显示当前无私人素材的参数预算，复用服务端正式计价公式，仅返回总积分；不返回余额、快照或执行许可。含私人素材时仍须登录校验，不按无参考素材偷算价格。参数恢复为合法质量后立即清除该项旧错误，不能长期残留“不支持”提示。此条覆盖旧的游客一律隐藏预算规则。

- 会话工具栏按输入框实际宽度自适应：640px起展开模型、风格和模板文字，820px起展开参数摘要；窄聊天列仍使用图标和Tooltip。长名称省略，积分与发送保持同组常显。此条覆盖旧的“所有会话只显示工具图标”规则。

- 会话输入框上方不再单独显示“本轮参考素材”条及文件名按钮；仅隐藏该展示栏，保留原用户消息中的素材、资料库文件和后续创作引用上下文。此条覆盖下文旧的独立参考栏展示要求。

- 顶部用途导航为自由创作／短剧／电商／广告／音乐·MV。电商commerce与广告marketing各自独立草稿、标题、推荐和五类目录，底层共享编辑器、素材、技能身份、模型及真实计费。电商分类为推荐／主图与详情／商品展示／内容种草／口播带货；广告为推荐／品牌广告／信息流广告／达人营销／节日促销。跨入口技能配置entry_categories多选关联，不重复建技能。旧commerce链接、技能版本及会话许可保留，未完成流程不新增虚假可用卡片。

- 发送键左侧积分按当前模型、比例、清晰度、质量、数量、时长、提示词和真实素材读取服务端只读预算，不再展示整个模型最低档起价。参数变化立即清空旧值，防抖并丢弃过期响应；未登录、预算失败或尚未报价的导演阶段隐藏数字。只读预算不调用LLM、不冻结素材、不授权生成或扣费；实际生成仍需总价确认。

- 生成确认卡在报价上方说明“确认后将立即提交生成，执行期间无法取消”，沿用真实报价与费用确认。次按钮“稍等一下”停止当前待确认方案，不影响已提交媒体或其他任务；等待服务端确认后撤下卡片，显示简短停止反馈和真实用时，刷新历史保持一致。停止失败保留确认状态并允许重试，不伪造已停止；停止中禁用确认与重复停止。

- 输入框参数、积分与发送在同一不可拆行操作组，积分紧邻发送左侧，仅显示 CreditIcon 与整数数字；不显示“参考”“积分／张起”等正文。有值的完整说明保留读屏和悬停，没有数值时整项隐藏，不显示“先规划脚本”等占位。真实生成确认卡及计费口径不变。

- 账户菜单文字保持图标旁左对齐，“居中”仅指44px行内上下居中，禁止把菜单文字横向居中；余额卡中的购买积分按钮仍保持按钮自身内容居中。

- 用户委托临时使用的第三方公开展示媒体必须保留来源记录，详情明确“临时参考媒体、非本站生成作品”；预览最多十秒静音，不作为生成参考或商业授权。公开目录的媒体宽高比仅约束卡片展示，不扩大生成模型比例、时长或收费能力。

- 电商场景批量上架后，首页输入框下的快捷技能最多显示目录顺序前八个真实推荐；完整推荐和四类技能仍在下方瀑布流浏览，不让几十项快捷入口挤占首屏。展示占位封面与生成参考素材隔离。

- FAQ四个折叠标题统一52px最小行高，文字与箭头垂直居中；每项底部分界线完整保留，普通问题与积分参考表之间不另留断层。账户菜单行高44px、图标与文字居中；余额卡内购买按钮36px高、20px文字行高，保持中性卡片和主题色按钮各自独立。

- 案例播放器底栏最新规格：80px高、背景令牌`#2A2733`；操作按钮56×44px椭圆、背景`#292439`。视频下角24px圆角，进度轨中心贴合视频底边，底栏常显且不显示时间文字。模型选定后发送键左侧显示只读“参考整数积分／单位起”，普通对话也显示；不以取整单位价推算任务总价，不在打字时调用LLM，实际费用仍以生成前总价确认卡为准。时长滑块实时秒数显示在标题，不再在端点重复浮层提示，避免“秒”被遮挡。

- 案例播放器底部进度与播放／声音／上下条操作始终显示，不再跟随悬停隐藏；不显示时间文字，时间值保留给辅助读取。轨道3px、圆点10px、操作按钮44px、底栏64px，四按钮均匀分布；可操作控件使用pointer，禁用项not-allowed。顶部关闭／放大／复刻仍悬停或键盘聚焦时显示。

- 案例点击默认右下角小窗，不遮挡首页，横屏最大560px／竖屏320px，打开静音自动播放；真实播放状态驱动暂停、静音、进度和上下条。桌面悬停／键盘聚焦时显示控制栏，触屏常显；左上关闭与放大，右上复刻同款，底部USlider及操作区。放大使用同一个媒体节点切为主播放器＋右侧真实案例列表，下方真实标题简介；返回不重置进度。不复制外站素材或伪造创作过程入口，原复刻确认和发布校验不变。

- 短剧输入框隐藏模板按钮，案例关联配方与复刻校验保留。案例卡片统一16:9；播放按原视频比例限于视口，移除视频外标题和说明，复刻／全屏／关闭使用视频上层图标按钮和Tooltip。不得用object-fit:cover裁掉播放内容；原文件自带黑边需单独校验并生成展示衍生物，保留原片。

- FAQ 正文、问题和表格统一16px，辅助说明14px，保持原固定高度与内部滚动。兑换码复用LivDialog settings dark及LivButton settings；个人菜单顶部余额卡保持中性底色，仅右侧“购买积分”为主题色按钮，原“积分充值”菜单改“积分账户”。预估积分与发送按钮同组，放在发送左侧，不再单独占上一行；不改变实际核价与确认流程。

- 常见问题默认高度780px，桌面不超过视口减64px、窄屏减32px；折叠与展开参考表不改变外框高度，标题和关闭固定、正文独立滚动，不允许长表格撑出框。参考积分向上取整仅用于展示（12.5显示13积分／秒起），实际报价仍按本次总预算核算，不按取整单价逐项相乘。

- 充值弹窗常见问题入口固定在标题栏左侧，复用UModal actions槽，不占账号卡与套餐间整行；FAQ积分参考表默认折叠，同次开合保留已读取内容，重新打开FAQ恢复折叠。示例、最终确认价边界在表头统一说明，不在每条金额下重复；未启用状态仅在模型合并单元格提示一次，真正缺价逐项说明原因。

- 常见问题为宽版只读参考表例外：复用LivDialog settings dark reference，最大1040px、视口四周32px／窄屏16px；标题固定、正文独立滚动，问题与表格文字统一亮白。积分表按图片／视频／音乐分组，模型和分类用真实rowspan合并单元格、细边框网格；不得复制第三方价格、会员折扣或未开放能力。充值与个人菜单共享唯一FAQ宿主，关闭后保留充值套餐、账单和创作草稿。

- 用户端不再展示创作区右上角常驻“安全协议”摘要及感叹号；删除其专用展示状态与重复目录请求，协议正文入口、真实授权弹窗与提交前服务端校验保留。后台模型标识编辑使用可读文字框、选中色块及带色块下拉；历史兜底默认开关位于基本配置，业务绑定仍由功能模型配置维护。

- 普通全局公告仅登录后自动显示，复用 LivDialog settings dark 居中弹窗，完整正文独立滚动，不再使用右上角气泡。每次加载最多提示一条，关闭按账号及内容版本隔离，不等同已读。游客、退出账号及旧请求迟到均不展示；全部公告页不叠加弹窗。顶部铃铛仍直达全部公告，独立维护拦截不受影响。

- 窄屏创作导航展开后，关闭键固定在侧栏自身右上角，不复用左上角展开按钮覆盖 Logo；关闭／Esc 后焦点回到展开入口。位置随实际侧栏宽度变化，不另写固定横坐标。

- 视觉风格选择使用大尺寸UModal媒体浏览器，最大1160×780、桌面四周48px、窄屏16px；背景磨砂，顶部四范围／搜索固定、分类和竖卡内容独立滚动。宽屏七列、16px间距、3:5竖卡；没有真实封面显示明确占位，不复制第三方封面、作者、热度。个人风格与收藏复用资料库style图片分类、真实分页与收藏接口；上传JPG／PNG／WebP沿用真实配置与服务端格式验证，显式选择才引用固定版本，不自动生成；普通曲风仍保留文字输入。

- 提示词恢复入口采用正文首行前的灰色小卡片，与首行文字并排，不单独占行；仅首行预留卡片宽度，后续行回到左边缘。按钮独立于contenteditable，不把“Ctrl+Z恢复原提示词”写进复制／发送内容，点击及快捷键撤销逻辑不变。

- 技能使用最新规则：快捷使用／卡片及详情试一试会填入公开示例，不再显示“已选择技能”成功Toast；保留素材、不发送生成。编辑区提供可点击的“Ctrl+Z 恢复原提示词”，每次有效替换记录文字与可编辑字段快照，可逐次撤销，不恢复旧报价或授权；历史仅当前页面内最多100步，切换账号／入口／会话或执行时清空。手动编辑优先保留原生撤销，空框Tab示例继续保留，此条覆盖旧的“试用不填入文字”规则。

- 快捷技能悬浮预览只保留媒体、名称和两行公开简介，不再放重复的“使用”按钮。仅保留快捷技能条旁的“使用”，与技能卡“试一试”统一白底深字胶囊样式；主体点击查看详情、使用只选能力不发送的边界不变。

- 2026-10-21 模型与技能最新规则覆盖旧数字人工具展示：AI口播使用普通平台视频技能与共享问答／确认链；阿里专用数字人接口与历史保留，存在普通口播技能时不再展示未配置工具占位。快捷技能用 UPopover 原生悬停预览与独立“使用”；点击主体只看详情。短剧固定后台制作能力，仅显示比例，移除技能选择与外框。模型浮层为图片／视频／音频连续分组，Tab 滚动定位、手动滚动同步分类，仅点击模型行才更改规格。模型最多两个纯文字主题标识，颜色及浮层规格复用主题令牌。

- 入口收敛最新规则：图片创作只隐藏顶栏及初次用途选择，不新增图片快捷入口；旧 image 路由、历史和能力保留，商品主图／海报设计在自由创作技能中可选。广告输入框移除直接／导演切换，改由“广告短片／广告创意短剧”选择；仅显式选择技能决定新流程，历史广告导演和旧模板不重写。故事模式本轮不变。
- 短剧沿用上传剧本／粘贴剧本／描述想法三种真实模式，使用共享 UTabs 顶部连体页签；选中表面与正文相接，左右反向圆角，切换保留文字，不新增视频转换或自由画布能力。模板可编辑字段使用高对比浅靛紫文字与专用背景令牌，不更改品牌实心主色或安全分段逻辑。

- 技能页由同一 CreationStudio 承载目录和唯一 CreationComposer，不再另写简版输入器或在试用时跳回首页。首页顶部、首页停靠、技能页常驻底栏使用相同编辑器、草稿、上传、参数、模板和发送链路；收起只切呈现，展示已选技能和需求摘要，试用展开到最大800px。技能页隐藏首页用途 Tab、英雄区和重复推荐区，目录采用共享瀑布流／详情／试用按钮。分类18px／700、选中800；推荐仅根据真实推荐标记筛选，搜索及分类不改变草稿。
- 技能页试用先读取当前可用版本，本页选能力并展开，不自动填入或生成；短剧／音乐等需要跨入口时先保存旧作用域，有内容则明确确认，再恢复目标作用域的草稿，路由仍留在技能页。等待技能状态期间锁定输入工具与发送，离页或换号后的旧响应不生效。数字人口播沿用专用工具，未配置时禁用，不混成普通平台技能。

- 技能卡与案例区分：首页技能和技能中心统一自然比例瀑布流，5／4／3／2列、12px间距。技能名置于左下薄黑渐变层，悬停／键盘聚焦展开两行简介及右下“试一试”，触屏常显试用入口。点击媒体先看详情，不立即选用；详情复用 UModal，标题左侧、分享菜单／收藏／试用与关闭右侧，媒体在前，下面依次为技能简介、适用场景、使用方法、输出内容。公开说明通过独立 public_guide 配置，不解析内部执行文档，不复制第三方媒体、文案或原始提示词。
- 技能“试一试”仅重查可用性、选定能力并展开输入框，保留已有草稿和素材，不提交生成；停靠时直接扩为大输入框，不跳回顶部。空框显示公开示例，按正向 Tab 才通过现有模板分段器写入可编辑字段，Shift+Tab／输入法组合／已有文字／任务进行中均不覆盖；模板依旧点击直接填充。缺少公开场景说明明确未配置，公共分享链接仅恢复详情，不自动选用或执行；私人技能不提供公开分享。

- 最近项目四项操作菜单采用紧凑规格：宽 200px、文字 13px／500、图标 16px、行高 36px；修改封面必须有可用图标。三点按钮固定占位、悬停显示，不因显隐重新排版；组件延迟关闭事件只能关闭自身，不能清除随后打开的其他行菜单。继续复用 UPopover 原生悬停范围，不叠加业务关闭计时器。

## 1. 技术边界

用户端统一使用 **Nuxt UI v4 + Tailwind CSS v4**。

- Nuxt UI 负责按钮、图标按钮、输入框、下拉框、徽章、菜单、提示、弹窗、抽屉、单选组、进度、骨架屏和文件上传等通用交互。
- 剧本内容、资产卡片、镜头卡片、导演方案、时间段、连续性检查等业务密度高的组件保留 Livliv 定制结构。
- `components/liv-ui` 作为过渡兼容层，内部必须基于 Nuxt UI，不再维护第二套弹窗、菜单和下拉交互。
- 页面不得继续使用浏览器原生 `alert`、`confirm` 或自行实现的全局浮层。

## 4. 控件与间距

- 全入口比例区固定仅显示 16:9／9:16／4:3／3:4／1:1／21:9 六项，不追加目录中的 3:2、2:3 等扩展比例，弹层最大 384px、固定六列单行；不支持项置灰并提供原因，不能擅自扩大模型能力。共享样式作用在传送层自身，首页／会话、自由／图片／广告／短剧／MV 同步生效；写歌等无画幅参数的能力仍保留其实际专用设置。

```text
控件高度           32 / 36 / 40px
图标按钮           32 / 36 / 40px 正方形
间距               4 / 8 / 12 / 16 / 24 / 32px
圆角               普通控件 8px / 菜单 16px / 设置弹窗 24px
设置主按钮圆角     胶囊形（999px）
```

- 同一操作组内的按钮必须同高。
- 会话左上角按最新偏好恢复 Livliv 品牌点击下拉，包含工作台、我的项目、资料库、技能及展开／收起导航；保留最近项目和新建入口。音乐候选卡的“第几首”固定在独立列，曲名省略不能截掉序号；不同音轨不得按同名误删。
- 同一行顶部左右一级入口（导航／会话胶囊、积分、通知、账号）统一 `--liv-topbar-control-height: 40px` 外框，包含边框和内边距，垂直居中；不得各自使用 32／38／44px 造成高低不齐。内部图标按钮 32px、图标 18px、头像 32px；窄屏可隐藏文字，不能只缩小其中一个外框。
- 数量及数值输入使用 `UInputNumber` 的加减步进器，不直接使用浏览器原生 `input[type=number]` 箭头。必须配置真实最小值、最大值和步长；保留禁用态、键盘输入与边界反馈，禁止用隐藏原生箭头来冒充步进器。
- 图标按钮使用 `square`，并提供 `aria-label` 和 `UTooltip`。
- 页面区块不做漂浮卡片；只有资产、镜头等重复项以及真实工具面板使用卡片。
- 固定画幅图片使用 `aspect-ratio: 16 / 9`，动态状态不得改变卡片尺寸。

## 5. 按钮层级

- `solid primary`：当前区域唯一主命令，例如“确认资产并进入分镜”“生成镜头”。
- `outline neutral/primary`：返回、管理、编辑、预览等次级命令。
- `soft`：当前已选状态、轻量批量操作和非阻断提示。
- `ghost`：紧凑工具栏或列表行内操作。
- `error`：删除、失败重试等风险操作；删除必须二次确认。

按钮文案直接描述结果，涉及点数时显示为“生成镜头 · 300 点”。

- 积分与扣点动作的图标必须统一复用 `CreditIcon`，其底层只读取 `/public/icons/credit-star-light.png` 与 `/public/icons/credit-star-dark.png`。
- 禁止使用 Lucide、Nuxt Icon、内联 SVG 或手绘 SVG 代替积分图标；普通 AI 能力图标仍可使用图标库。
- 靛紫主按钮中的积分 PNG 统一转为白色显示，图标与点数文案必须同时保留清晰语义。

## 6. 状态与徽章

- 成功：`success`
- 处理中：`primary`
- 待确认或风险：`warning`
- 失败或阻断：`error`
- 普通信息：`neutral`

业务状态必须使用中文，不展示 `role`、`scene`、`opening`、数据库 ID 或供应商内部状态。方案状态、视频状态、验收状态分别展示，禁止合并成一个“已完成”。

- 用户可见的正文、状态、提示、错误与无障碍名称禁止出现“供应商”“上游”“ToAPIs”等接入术语，使用“正在生成作品”“生成进度”等业务表述；技术来源仅留在内部字段、日志和管理端。模型名称保留真实名称，不伪造能力。
- 进度接口明确返回的百分比必须传递到工作台并显示，包含合法的 0%；没有真实数值时只显示阶段或不定进度，不用等待时间估算。刷新后从持久化进度记录恢复。

## 7. 三阶段一致性

### 剧本

- 顶部页签、体检状态、建议类型使用统一徽章与按钮尺寸。
- 建议列表保留定制结构；生成优化稿、查看优化稿和采纳使用统一按钮。
- 优化过程使用 `UModal`，详细建议和全文对比使用大弹窗或抽屉。

### 资产

- 角色、场景、道具页签保留业务样式。
- 全选、新增、重试、批量生成、批量锁定和阶段确认使用统一按钮。
- 资产编辑使用 `UModal/USlideover`，版本、音色和上传控件使用 Nuxt UI。

### 分镜

- 总览工具栏、选集、状态筛选、风险筛选、视图切换使用统一控件。
- 快速审核和导演段落编辑使用 `USlideover`，整集统调使用 `UModal`。
- 镜头卡片、导演段落和连续性结果保留定制视觉；卡片内菜单统一使用 `UDropdownMenu`。

## 8. 迁移规则

1. 新增功能优先使用 Nuxt UI，不新增同类基础组件。
2. 旧页面先通过 `components/liv-ui` 兼容，再逐步替换为直接使用 `U*` 组件。
3. 不为了替换而重写高复杂度业务组件，避免破坏剧本、资产与镜头的数据链路。
4. 任意新增颜色、字号或圆角必须先进入主题令牌；页面禁止继续堆积任意值。
5. 每次迁移必须通过构建，并在 `1920x1080` 与 `1440x900` 下检查溢出、遮挡、菜单定位和弹窗滚动。

- 主题与规格令牌维护在 `assets/css/main.css` 的 `--liv-settings-*`，业务页仅使用 `liv-settings-copy/row/note`。需要新规格先补令牌与规范，再复用。
- 验收至少检查标题/按钮/开关的实际计算样式、键盘焦点和 Esc、未保存关闭不落库、保存后重新打开，以及窄屏无溢出；编译通过不等于这些交互通过。

## 13. 加载占位标准

- 助手“思考中”的省略号允许错峰呼吸，遵守减少动态效果偏好；不得以动画伪造工具执行状态。
- 普通图片、视频与音频方案就绪后自动读取真实报价，模型、规格、预估积分合并成一张确认卡，底部为主题色白字居中的“确认生成”和“取消”。不再要求先采用方案、再核对报价、再确认；报价失败显示重试，不能填写假积分。取消只停止当前待确认方案，不影响其他任务。刷新恢复报价不自动授权或生成；原有用户明确保存的免确认规则保留，导演分镜等必要编辑流程不跳过。

- 首次读取页面资料、切换会话恢复历史、工具栏读取模型与技能目录、案例列表读取数据时，优先使用 `USkeleton`；统一复用 `DashboardSkeleton` 的页面、会话、工具栏、卡片变体，不再用整片空白或“加载中”文字代替结构占位。
- 骨架尺寸跟随实际内容：会话包含消息、编辑器、底栏与画布；工具栏保留图标和右侧发送键的位置。工具栏加载只替换工具区域，不重建正在输入的编辑器、不清空草稿。
- 仅真实读取期间显示骨架，成功后显示内容，失败后退出骨架并提供错误和重试；不以骨架掩盖空数据、永久等待或读取失败。
- 生成、上传、支付等业务过程继续展示真实任务状态与可用操作；助手已返回的文字不能被骨架覆盖。占位容器提供中文可访问名称和 `aria-busy`，减少动态效果偏好下关闭闪烁动画。

## 14. 画布、产物与连续需求

- 音乐参数浮层使用 320px 紧凑宽度，“歌词／纯音乐”区分是否有人声歌词；摘要同步名称。同次任务返回不同音轨各保留一张卡，显示真实曲名和第几首，不合并不同音频。歌词模式与纯音乐描述冲突时先澄清，不默默修改类型、不重新执行历史作品。
- 创作者协议入口为独立只读页 `/creator-agreement`，合并版未发布时完整展示四份当前已发布条款，保留真实版本信息，不自动发布新协议。登录以一处勾选统一确认服务、隐私与创作条款；读取页面不写入同意记录。旧登录态缺失当前创作条款时回登录明确确认，不批量补签或自动重放生成；支付、上传等独立告知仍保留原许可边界。协议正文及链接使用主题令牌，去掉重复确认长列表，不复制第三方的独家代理或商业许可。

- 视频主工具栏保留“保存截帧／引用续作”，通过提示区分本地截帧与需报价的 AI 创作；通用视频创作台收进“更多工具”，不得以“视频同款与口播”暗示所有视频均能直接转换。打开工具不执行新任务、不自动授权，原创作台能力继续保留。

- 图片画布内 Ctrl／Cmd＋滚轮以鼠标位置缩放，范围 25%～400%；普通滚动和弹窗输入不拦截。右上显示真实缩放百分比，生成进度独立显示；适应窗口与全屏使用不同图标。
- 上下工具距图片默认 8px；缩放、平移后钳制在画布可操作范围。底部编辑按钮高 40px、图标 20px、文字 14px，窄屏横向滚动。
- 当前会话产物在“本地编辑免费；AI 工具需在对话中核对报价后提交”说明下方横向排列，居中于说明与画布底边之间的剩余空间，不贴工具栏、不吸附底边；缩略图使用统一令牌 80×64，不显示“产物”标题和总数，仅保留新作品圆点与读屏通知。窄屏横向滚动，悬停或聚焦浮层预览，不挤动列表。编辑版本归原产物版本菜单。切换复用未保存确认，保留输入草稿；新产物追加、按真实来源去重，后台完成不抢当前选择。
- 聊天完成结果使用左图 64×48、右文的卡片，按消息 ID 即时更新。同任务多个结果归同一助手上下文；终态缺少结果时只重读原任务，失败提供重试，不重新生成。
- 模型选择固定为图标／两行文字／选中标记三列；名称 14px、介绍 12px，单行末尾省略，不展示内部接入名称、重复规格或无配置推荐标签。
- 未主动切换技能视为需求续改，继承需求、已确认参数与补充答案，不继承旧报价、执行许可和执行标记。明确切换技能在同会话建立新轮次，历史聊天与产物保留；助手推荐不算主动切换。
- 问题卡回答使用回答接口，底部自由输入走需求修订。响应中先停止再发送，不排队、不替换、不取消已提交作品。停止须经服务器确认，失败明确重试；迟到响应按会话、流程和调用序号隔离。连接中断读取原流程，不重放创建。
- 新需求使旧待确认报价与倒计时失效；收费生成继续使用真实报价、确认和执行许可。
- 首次恢复时按持久化消息顺序重建产物目录，之后按新结果到达顺序原位追加，不能让并行轮询改变已有缩略图位置；同一任务新增的未选中结果也计入新产物提示。
- 只传部分参数的同技能续改继承未改动的技术规格；完整生成需求必须含已回答约束。停止结果即使先于下一次调用计数落盘，也必须结束响应态，不能被等待调用序号挡住。
- 选择“自由创作”时使用其合法自由入口，包括恢复的历史草稿；不得把“图片入口＋自由创作技能”的业务拒绝误报成网络中断。保留当前会话、历史产物及新输入。
- 助手名称右侧显示真实响应计时：进行中“已用时 N 秒”，结束后冻结为“用时 N 秒”。服务端保存本轮开始、结束、首段正文时间及耗时；刷新可恢复。历史缺少计时记录时不凭更新时间推测秒数，计时不等于生成进度。
- 缩略图的图片预览复用 UTooltip，内容高度自适应，不能沿用单行提示的固定高度；完整图片与说明一起参与浮层定位，默认在缩略图上方 8px，距离窗口边缘至少 12px。
- 会话报价占正常布局的独立信息行，与参数／发送组间隔 8px，不用绝对定位覆盖按钮。生成面板不显示更新时间；标题与详情相同时仅保留标题，真实百分比包括 0% 继续显示。
- 活动流程与历史流程使用同一时间轴，结果卡归属发起流程，固定在本轮方案之后；多结果不重复助手标题，历史恢复和迟到结果不改变轮次顺序。结果摘要优先使用完整生成需求，不能只显示确认短句。
- 技能 Markdown 专业文档与任务输入契约见 `docs/skill-task-input-contract.md`。确认卡、报价和实际执行消费同一服务端校验快照，模型回复不等于生成授权。
- 添加素材菜单保持紧凑宽度 260px，图标固定 18px 且不参与正文拉伸；模型菜单宽 320px（窄屏两侧至少 12px），顶部图片／视频／音频三类等宽 Tab，模型图标在 32px 容器内双向居中。不新增无配置支持的开关或标签。
- 图片区必须按实测工具栏、说明和产物栏高度预留底部空间；放大图片只在媒体区裁切，不得通过把工具栏向上挤压而覆盖作品。
- 任务失败原因复用服务端脱敏文案，在对应消息组以 12px 灰字和错误图标显示；实际开始重试才显示尝试次数。工作台图片仅对明确终态且可恢复的错误自动尝试，含首次最多三次（最多两次重试）；状态未知继续续查，审核、参数、权限错误不自动重提，不为绕过审核改写描述。
- 对话任务通知水平居中：已提交使用紧凑灰色卡与绿色勾选图标，仅代表提交成功，不代表作品完成；已知失败模板显示简短原因，完整脱敏原因保留在悬停／键盘焦点提示中。状态尚未读取不显示绿色成功提示。
- 左右生成状态保持同步：左侧对应消息在排队、生成、重试和读取结果时展示转圈图标及阶段文字，不一直停在绿色“任务已提交”。百分比与画布共用该消息的 taskActivity.progress，合法 0% 保留，没有真实值不估算。断线显示同步状态并去掉旧百分比；失败显示原因，完成由结果卡接替。助手响应用时不等于作品生成用时。
- 合规建议使用简洁业务文案：整理阶段“正在重新整理中…”，候选输入框上方“建议按以下内容生成：”。不重复“尚未重新生成”等内部执行边界说明；此文案不代表已经提交生成，真实任务状态仍独立显示。
- 隐藏标签页暂停只读 GET，前台恢复后继续；同页相同鉴权与参数的在途读取合并，不缓存已完成私人数据，不合并带取消信号的读取或写操作。局部初始化失败不得以全页错误遮挡深链会话；余额尚未读取显示“—”，不得显示默认 0。会话限流应提示稍后重试且原任务继续，不能误称网络断开。
- 审核失败保留原任务，不显示“AI 帮我调整”空入口或外层灰色空卡。上方提示“未通过安全审核，可以使用以下建议：”，AI 建议必须填入一个可编辑 UTextarea，不得改成普通正文段落。下方确认／取消等宽并排，统一使用 LivButton settings：确认 variant="primary" 为品牌主题色 #4F46E5 实心、白字、40px 高、999px 胶囊圆角，与“下一步”保持一致；取消 variant="secondary" 使用灰色实心背景、白字、同高胶囊形，不能退化成细线矩形。最新一条历史审核失败自动读取／整理建议，其他旧失败不批量调用 AI。确认发送输入框当前内容后仍重新核价，取消只收起建议，不影响失败任务和草稿。新轮次不继承旧拒绝语义／素材，服务端校验来源。不能用同义词保留违规意图，不自动提交图片；参考素材无法确认时要求补充。重复点击或断线只读已有候选，整理最多轮询一分钟，超时明确提示。
- 会话骨架与真实工作区铺满主体可用宽度，不使用 1500px 居中限宽；顶部栏下保留上下左右各 12px 的会话外边距。桌面聊天区默认 390px、可拖动 320～560px，分隔条 8px，画布占据剩余空间；宽屏只扩大工作区，不拉伸媒体比例。宽度、分隔条和高度复用 `--liv-workspace-*` 令牌，局部恢复骨架继承当前聊天宽度；首页输入区和案例限宽不受影响。刷新恢复须在消息滚动容器挂载后定位到底部。发送与助手新回复主动回到最新，图片／建议等晚到排版通过内容高度观察补齐滚动；用户翻阅历史且没有新回复时不持续抢回底部。
- 建议框的“确认”同时表示本次修改后重新提交，无需第二次点击：本次操作内完成新方案整理、真实核价、新执行许可和原业务幂等提交。仅在原模型、比例、清晰度、质量、数量及金额均一致且余额足够时直接执行；改变或缺少原报价／规格时展示确认卡及原因。不复制旧执行许可，不使用全局免确认规则；刷新、断线重读和历史恢复不重建这次点击意图，取消和跨会话迟到响应不能继续提交。
- 点击建议确认或取消后立即收起该建议输入框与按钮；未成功接收新轮次时恢复原建议以便重试，已接收后由新消息、报价卡及任务状态继续展示，不保留旧操作区。
- 参数弹层字段名称和范围描述统一 14px／1.7，不因 small 标签或弹层传送脱离祖先而缩小。消息内不重复显示“停止响应”按钮，停止操作统一保留在输入区；工作台文字整理和审核建议由平台承担，不设每日 20 次限制，保留接口限流、单流程防循环和调用成本审计，不影响媒体报价扣点。
- 助手澄清选项直接显示灰色选项块，不套“补充创作信息”外层卡片；单选点击即调用回答接口，不先填入输入框。只有无选项的文字问题，或模型明确 requires_input=true 要求编辑建议时显示专用输入框。真正多选保留选择与统一发送，参考素材保留上传入口；底部自由输入和收费报价确认不变。此规则优先于旧的“推荐选项只填草稿”约定。
- 灰色选项在非禁用时提供 surfaceHover 悬停反馈和主色 focus-visible 描边；始终保留“其他／自行输入”兜底入口，点击才展开输入框，不自动发送。模型与文字目标冲突时应提供保留已选模型的方向，不强迫用户只在替代模型中选择。
- 生成确认卡的“不再二次确认”复用 UCheckbox，按当前图片／音频／视频类型立即保存当前会话同一份确认规则，与右上角设置同步；未读到规则、保存中或提交中禁用，失败不假装已保存。勾选本身不提交当前任务，超阈值、无法报价和服务端强制人工确认限制保留。设置弹窗使用 LivDialog settings sectioned：标题说明左对齐，开关按媒体分组、冷静期独立分区、阈值说明与输入并排，底部右对齐取消／保存；取消不保存草稿，主色仍为 #4F46E5。
- 流式回复仅在用户原本跟随底部时持续滚到底；内容变高、图片排版或程序滚动不能误判为用户上翻。用户滚轮向上、触摸上翻、键盘翻阅或拖动滚动条后暂停跟随，回到底部或主动发送时恢复。此规则优先于旧的“回复强制到底”约定。
- “修改上一答案”使用灰色次级按钮，仅在仍待补充问题、有历史答案且没有响应／提交时显示；方案已就绪、媒体已提交后不显示。返回只回填问题区，撤销旧报价和许可，不占底部自由草稿；回答完成自动分析并获取新报价，编辑区快照与服务端完整执行需求分开比较。
- “请确认本次任务”必须与该轮有效报价同时展示；模型、规格、积分核算完成前仅显示“正在核算方案与积分”，不提前展示缺价确认卡。正常新方案自动核价，只有真实核价失败才显示“重试核算”；需求已变而必须重新协商时不可用反复获取旧报价冒充新方案。
- 任务失败／超时通知只读，点击不切换右侧作品；真实成功结果仍通过结果卡选择。视频模板示例封面不得作为纯文生视频的结果封面，历史误用在读取时过滤，不重写或重生作品；无真实封面时播放器显示视频自身画面，缩略图可使用视频类型图标。
- 视频结果卡和产物栏无真实封面时使用静音、无控制条、无自动播放的视频首帧预览，不能拿模板图冒充结果。问题正文与选项组相距 12px，与选项间距相同。风格和创作模板保留在输入工具栏，加号只放上传／资料库素材入口，此规则覆盖旧的紧凑收纳规则。
- 工作台保存、提示等轻量反馈复用 UApp 右上角深色 Toast，正文 14px／1.7；不在顶部中央再画一套小字号悬浮条。相同参数、无操作的弹层开关、目录重读不使有效确认卡消失；真实技术参数修改撤销旧报价并自动核价，新价格与规格一起显示。
- 视频审核失败复用图片合规建议交互，仅整理原始需求及审核风险，不自动重提媒体；素材问题要求检查素材。采用建议仍须校验来源、归属、原媒体类型、模型、时长、规格与金额，变更时重新确认；不继承旧执行许可。
- 资产引用统一从加号“添加素材”中的“从资料库选择”进入，工具栏不重复显示资产文件夹按钮；上传和引用能力保留。已选风格在输入工具栏显示缩略图／图标和名称标签，悬停可读完整名称，右上角提供可聚焦的“清除风格”叉号；清除同时置空 style 与 styleId，不改变其他需求、素材或规格。未选风格时仍显示调色盘入口，受技能锁定时选择和清除均禁用。
- 小输入框（compact）的已选风格收紧为 32px 图标标签，只显示缩略图／图标和右上角叉号，不显示名称或省略文字；名称通过悬停与键盘聚焦提示、无障碍标签完整保留。大输入框继续显示风格名称。
- 大输入框风格标签按名称内容自然伸缩，不预留固定字数宽度；受容器限制时允许收缩省略但不能挤掉发送键，小输入框 32px 纯图标规则不变。

## 15. 技能管理与内容自适应工作台（2026-10-17）

- 后台模板／公共素材／案例列表使用明确列宽和横向滚动，名称省略保留完整提示，操作文案保持横排，不通过压成单字竖排适应窄宽度。模板增加分类／状态筛选，编辑分内容／示例媒体／展示设置；内置预设由已登记平台站点媒体映射，禁止写死 localhost 用户端端口，失败使用稳定占位。公共库默认“公共素材” Tab，用途分类和容量设置独立；容量按 MB／GB 输入但接口仍存字节。用途、类型、状态筛选须在服务端分页前执行，查看归档不扩大普通用户的公开权限。所有上传复用 Ant Upload，固定版本与发布依赖校验继续保留。

- 后台案例发布确认最大 560px：公开作品与范围独立摘要区、权利确认独立一行、依据输入独立字段。Ant Checkbox 自带 label，必须避开普通表单 label 的 grid 规则，16px 勾选框与 14px 标签首行对齐，禁止框与文字上下分离。依据未填或未确认时禁用发布，服务端校验继续保留；文案不暗示商业许可。

- 后台案例编辑采用“案例内容／展示设置”两个 Tab、最大 960px 弹窗，标题与保存区固定、正文独立滚动；内容区维护名称、简介、互斥来源与并排封面／媒体预览，窄屏上下排列。复用 Ant Input、Select、RadioGroup、CheckboxGroup、InputNumber、Upload，禁用原生裸上传及手填媒体类型。类型由真实上传／授权输出识别，媒体不自动播放；失败有占位。授权选择显示已有案例标题／类型及授权时间，缺名不读取私人提示词，编号不作为主标签。展示设置放入口、可选模板、排序、只读发布记录；保留不兼容绑定并要求显式更换／清除，不静默删除。保存按钮明确为“保存草稿”，修改已发布案例须重新发布；公开展示权、依据和媒体可用性继续由独立发布接口验证。

- 平台技能支持基于已接入能力新建，名称、Markdown、素材与发布独立维护；基础能力只能在新建时选择，默认停用。文档参考来源为完整宽度的多行输入，每行一条、最多十条，空值明确为可选而不是缩成空白小框。历史迁移来源只对确有旧字段的已有技能显示，新技能不显示。推荐参数明确“留空即沿用平台”，一键推荐仅补真实共同规格中的空项，不强填无交集参数、不覆盖已配值。
- 后台素材选择复用 Ant Design Upload／Button，禁止原生文件输入裸露；固定引用显示名称、版本、已选数量与移除，素材网格两列、窄屏一列，最多十二项。封面使用稳定比例的预览框及加载失败占位，内置用户端静态路径须解析到平台库预览，不能直接请求后台同名路径。发布开关保持组件原生尺寸，禁止在 grid 中横向撑满；来源、封面地址等折叠内容有统一内间距。

- 我的项目保持铺满工作区：标题 24px、说明和控件 14px、项目名称 16px、辅助信息不低于 12px。工具栏统一 40px，搜索／状态／排序默认 280／144／200px，仅在项目目录约束，不改变通用下拉框；右侧批量和视图操作不拆字，窄屏按完整控件换行。明确提示“搜索本页项目”“筛选和排序仅作用于当前页”，不伪装成全量检索。
- 项目网格按内容容器宽度显示 1～6 列，紧凑规格为间距 12px、卡片正文内边距 12px，封面 16:9、最高 144px；统一裁切／占位且同排等高，骨架共用项目尺寸令牌。名称仍为 16px、日期等辅助文字不低于 12px，不通过缩小字号压缩卡片。普通会话卡只显示名称和更新时间，移除重复的“继续对话”及泛化作品说明；整卡点击与键盘打开行为保持不变，仅为关联短剧制作和其他会话保留不同目的地入口。名称省略时保留完整提示，列表视图同步简化重复操作、字号、进度和状态。常规状态靛紫、完成绿色、待处理警示、归档中性；不改变接口返回的业务状态与进度。图标操作使用现有 Nuxt UI 并提供无障碍名称和提示。
- 最新项目规则覆盖旧的“会话独立横排”：我的项目统一管理会话创作和短剧，分类为全部／自由创作／短剧；分类在服务端分页前执行，搜索／状态／排序仍明确仅作用当前页。纯讨论也保留卡片，不显示虚假完成度；封面只来自本人已完成作品，不拿参考素材或视频模板当成果封面。按真实短剧绑定去重，一份短剧多个会话仍只显示一张卡且保留全部对话入口；同会话生成多个短剧则每份短剧独立一张卡。关联卡默认继续最近对话，并提供进入短剧制作；无会话的短剧仍进入原工作流。
- 新建项目提供自由创作（首选）和短剧专业流程，不再默认创建空短剧。左侧最近列表与顶部浮层统一称“最近项目”，复用同一服务端目录和十条分页。底层会话、作品和短剧不合并、不回写历史；批量管理和删除只作用已有短剧接口，确认明确保留关联会话与独立作品，不能拿会话编号调用短剧删除。当前未接入自由项目删除，不伪造成功或借用短剧删除接口。
- 最近项目的前置图标优先显示目录真实作品封面，复用 UAvatar 的图片及失败回退；24px 等框、8px 圆角、居中裁切，无封面或加载失败保留原类型图标。标题仍省略并可读完整提示，不改变项目点击、更多分页及菜单行为；不逐项目新增任务请求、不使用参考素材填补缺图。

- 资产网格中“生成／上传”入口与同排实际资产卡共用外框高度，不能仅按封面高度截短创建入口；图片、合集与文件保持网格对齐，音色列表保留独立横向规格。首页案例封面为 16:9、最高 144px，图片在比例容器内裁切，不依赖原图内在高度；推荐区上间距 32px。
- 输入框技能菜单宽 480px（原 460px 增加 20px）；外框 422px，列表区固定容纳四行（64px×4＋4px×3＝268px），标题／分类／创建入口不参与列表滚动。全部／我的及分类切换不改变外框高度、宽度或展开方向，空列表也保留高度，超过四行内部滚动。仅打开时按四行高度和视口空间选择上／下方向，开启后禁用内容驱动翻转；窄小视口按实际空间缩短列表，不裁掉分类与创建入口。规格统一复用 `--liv-skill-menu-*` 令牌。

- 会话外壳继续铺满；有媒体产物或执行任务时使用 390px 默认聊天列、8px 分隔条和剩余画布，纯对话正文则收为最大 760px，不预留空画布。已有 1500px 限宽取消规则不回退。双栏切换统一为 1024px，收起聊天只隐藏布局，不重建编辑器或播放器；新结果不抢当前选择。
- 主页导航维持原样，工作台默认隐藏；顶部只保留展开／收起导航、最近会话、新建创作和标题。完整导航仅点击展开，1440px 以上占位，以下复用 USlideover；不得在整条左边缘悬停就自动展开。
- 最近会话使用约 300px 的 UPopover，无独立遮罩、不改变画布宽度，悬停 200ms 打开、离开 250ms 关闭；支持点击与键盘、Esc。操作菜单或重命名进行中保持浮层，路由／账号切换和卸载清理延迟及旧请求。复用 DashboardSidebar 的十条分页、更多、重命名和当前项高亮。
- 骨架 layout 分 unknown／conversation／media：未知只展示中性外壳，已知纯对话为单列，已有媒体为双列，使用同一布局令牌；失败退出占位，目录局部加载不销毁输入草稿。
- 自由创作的模型触发器不因音乐只有一个引擎而失效；三类媒体可从同一浮层重新选择，固定专项能力说明清晰。模型目录以服务端 capabilities 为准；音乐操作与一般模型分开，不新增不存在的模型或价格。
- 自由入口历史空技能与明确 `free` 使用同一模型分类判断；仅选定模型时归一技能并同步产物类型，不清空文字、参考素材或已有作品。目录查询使用合法自由技能键，专项技能不因显示兜底名称而扩大能力。
- 后台技能管理延续 Ant Design，不套用户端深色设置弹窗。平台技能／用户技能／运行记录／全局设置按需加载，宽版编辑器分技能内容／素材／发布设置，正文滚动、保存区固定。Markdown 主编辑，旧规则默认折叠且无损保留；素材必须是已发布的平台固定版本，下架前显示依赖，新执行必须重新校验。不得把用户公开展示当成平台素材授权。
- 平台技能最新文字规则以 Markdown 为唯一编辑入口：分类／固定能力只读，附加素材要求归素材 Tab，参考来源归文档辅助区。高级规则只分模型限制／推荐参数／限制规则三组，默认折叠并显示真实覆盖摘要，不计算系统步骤和默认全开放项。模型策略沿用平台时不展开绑定；音乐不出现普通模型表单，只有多流程技能才出现流程选择。推荐参数取全部候选真实规格的交集，无目录／无交集不猜测；旧不兼容值警告保留，并提供显式恢复继承。隐藏的历史参数不能随保存清空。
- 前后置约束、执行说明、示例和问答迁入 Markdown，旧字段仅在“历史迁移来源（只读）”核对；不再提供并行文字表单或步骤 JSON 输入框。生成前补充／生成后约束为受控 Markdown 二级章节，正文采用完整 text 围栏；预览只渲染 Vue 文本、标题和代码块，不执行 HTML。全量迁移必须预检、备份、单事务新增版本和迁移后复核，不覆盖历史配置；旧任务及个人编辑器保留兼容路径。
