# 创意审核与执行确认减负验收（2026-11-05）

## 本轮变更

- 继续复用 Deep Agents 结构化工具、原报价／免费准备及最终确认服务，不引入框架。
- 提示词要求模型结合完整原文、明确选择和最新修改判断 `review_required`，默认 false。首次制作、助手自行构思、单张／多张及未确认费用都不是增加创意审核的理由。
- true 必须提供具体 `review_reason`。缺少原因时交还模型修正，不由本地关键词替模型判断，也不因此给用户制造一轮问题。
- 各类新图片／视频计划统一保存本轮审核决定、原因及决定版本 2，防止只有部分编译入口保留标记、其他入口又重复审核。历史记录不批量改值。
- 免创意审核的新方案由后端原服务准备最终任务卡，展示真实规格和积分；页面挂载和刷新不 POST 报价，不自动提交采购。
- 必需的创意审核入口叫“确认方案”，修改为“更新方案”，准备失败为“重试准备”；不再使用“查看费用并继续”。最终收费按钮统一“确认执行”。
- 画布节点双点 loading 最大球 10px、最小 4px，轨道横向 6px／纵向 3px，容器 24×18px。全页加载大小、绕行行为和减少动态效果设置保留。
