# 音乐舞台与匿名分享实施记录（2026-10-17）

## 本轮实现

- 顶栏左右一级入口共用 40px 外框令牌；导航内图标与账号头像使用独立内部规格，不用文字撑高。已补 UI 规范。
- 共享 MusicPlayer 重做为靛紫氛围舞台：真实封面模糊背景、CSS 黑胶凹槽与播放旋转、玻璃歌词面板、真实歌词高亮／导出、真实曲目列表、进度／音量／随机／单曲循环。全屏移动同一 DOM，不创建第二个音频节点；减少动态效果时关闭旋转和过渡。工作台“生成视频 MV”仍走原对话报价流程，不在播放器直接扣费。
- 公开路由 `/listen/{token}` 匿名只读；不使用带账号凭据的业务请求适配器，不发生成／时间轴补建请求。公开内容只含选中歌曲的成品音频、封面、标题、风格、歌词及白名单时间轴。
- 私人播放页和创作画布增加“分享音乐”：先读取状态，明确勾选授权后开启；可关闭并使旧链接失效，再开启更换随机令牌。外网必须访问部署后的公网域名，不能用 localhost 或局域网地址代替；未增加隧道或部署。
- API 新增 `GET /music/shared/{token}`、本人作品 `GET/POST/DELETE /music/tasks/{task_id}/share`；查询不自动发布，开启需授权，仅允许完成的成品（不接受原始音频登记任务）。查询／变更均校验归属，匿名读取不暴露任务输入、素材、用户、费用与内部字段。
- 新表 music_shares 使用任务＋曲目唯一约束；开启／关闭在任务行锁中串行化，未关闭时重复开启复用链接；无需新计费链路。随机链接可以被任何获知它的人读取，不等同于身份验证。撤销不能回收已下载内容。
