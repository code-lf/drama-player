## 短剧资产图 mock 接线增量

- 角色、场景、道具批量生图复用既有 `dev_media_fixtures`。场景要求 16:9，角色／道具要求 1:1；缺样本在报价时拒绝，不购买替代素材。

## 本批已接线

- 风格工具读取同一注册目录，选择卡复用 `CreationStyleDialog`；平台选择只提交 ID 与所见版本。服务端保存完整指导，图片／视频计划逐项冻结，核价传递内部快照，实际提示词包含完整指导。失效 ID／版本拒绝，客户端自报快照不生效。
- 个人风格通过原资料库 `resolve` 核对账号、条目、版本和媒体类型，再校验风格分类；与平台风格互斥，不把封面伪装成注册提示词，不增加生成授权。
- 短剧画布投影真实剧本、资产、按集/场组织的分镜及固定成片来源。原阶段组件保留唯一实例，在画布内的宽制作面板打开，不重复挂载底部工作台。
- 资产节点带 `type:key` 定位原资产详情；保留角色／场景／道具的已知设定字段、来源标记和出处数量，画面提示词与设定正文分开。后台回包缺少来源时不编造“剧本事实”。
- 节点拖动仅保存按账号、项目、剧集隔离的本机坐标。大项目新增 Nuxt UI 可搜索节点定位，避免全图缩小后无法操作；窄屏页头独立横滚，不撑宽整个页面。
- 已选择短剧入口的长文本粘贴提供直接粘贴／转 TXT，默认阈值 2,000 字；原文、换行与制作要求不混写，转换仅准备文件，不伪装已上传或发送。
- 开发目录 `.nuxt-*` 进入忽略清单，避免构建输出再次进入开发样式扫描。启动耗时不等同实际整页性能；本批未声称整页性能全面达标。

## 普通画布连线的实际语义

普通创作的可编辑手工节点：文本连到图片/视频草案后，点击该节点生成时读取入边，将上游文本和本节点提示词一起交给 AI 整理方案，再进入真实报价/确认。连线本身不生成、不扣费、不覆盖提示词输入框；改上游文本不自动重做已有作品。生成结果的历史追溯边不充当新输入。短剧画布目前只投影原业务来源，不允许随意连线更改剧情或资产版本关系。这两种语义不可混用，也尚非任意连线自动执行的 DAG 工作流。

## 本轮增量：镜头视频 mock 与确认合同

- 原单镜头/批次报价返回逐镜头确认指纹，绑定规划、提示词、素材引用、模型参数与固定样本；批次提交先核对整批，单镜头在创建 take 前再核验。零积分预算允许为 0，旧客户端空映射不改变历史幂等指纹。
- 正式准备服务把同一份 mock 快照写入 take 和 workflow，跳过媒体扣点及声音参考 MP4 制作；报价后改变模式、参数或样本必须重新确认，不能从零价切到真实采购。
- 正式 `execute_workflow_run` 在构造供应商客户端、凭据及限流器前分流样本。复用原存储、镜头选版、任务与批次回填；重复投递恢复原成片，不重复转存。样本损坏进入失败，不回落真实供应商。
- 测试视频不对应本轮剧情，不发送自动收费视觉质检；手动 QC 重试也返回明确样本状态，不伪造一致性通过。入队审计及画布详情保留测试身份。
