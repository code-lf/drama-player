# 入口参数与聊天 UI 补验

## 原因及修改

- 白猫会话的运行快照原本已带 `gpt-image-2-vip / 16:9 / 1K / low`。未生成媒体的会话没有媒体消息，恢复却只从媒体消息取参数，先重置为默认值；旧云端空草稿还会再次覆盖为 medium。
- 无媒体会话补读运行快照；旧默认草稿不覆盖已发送的技术规格，新版用户明确修改的字段单独保存。采用同媒体推荐技能保留已选模型、画幅、清晰度及质量。
- 助手明确接收已确认规格，重复的画幅用途选项做结构兜底。旧的待回答画幅卡只显示入口参数摘要及继续按钮，历史数据不删除。
- 等待选项时允许对话插话；模型判断为普通回复时保留原问题，不把“你好”保存成表单答案。
- 普通助手正文移除导演卡片样式与回复级设置图标；问题改为胶囊按钮及可发送的自由输入。输入框顶部圆角 24px，提示缩短，思考状态使用加载动画，两侧使用 #111111 表面令牌。
- 工具浮层复用 UPopover 的锚定、外部点击和 Esc；技能菜单去搜索及“内置技能”，创建入口右对齐。紧凑栏展示完整规格摘要，风格与模板保留在添加菜单。
- 真实 JSON 正文回调节流 100ms，SSE 快照读取 150ms；不补打字机动画、不伪造正文。

## 本轮验证边界

- 用户端结构回归 69 项通过；API 隔离回归 77 项通过。隔离测试不访问收费媒体供应商、不投递队列。
- 用户端生产构建通过；本轮后台未修改，未重新构建。目标聊天文件类型检查无新增诊断，但全项目仍存在原有画布/短剧等类型错误，不能宣称全量类型检查通过。
- 真实浏览器：刷新白猫会话后摘要和质量恢复为快速；输入框圆角实际 24px；聊天与画布实际背景 rgb(17,17,17)；用户气泡约 48px 高；头像名称左对齐。
- 等待选项时发送“你好”获得真实模型回复，问题保留且答案槽未被消耗；继续整理后得到沿用 gpt-image-2-vip、16:9、1K、快速的真实方案，未再次询问画幅。旧回复内容保留，不篡改历史。
- 真实浏览器确认参数浮层点击画布区域关闭；技能菜单无搜索和内置标题。当前实际视口 950×946，发送键在输入框边界内；指定宽屏及 390px 窄屏本轮未重新完成。
