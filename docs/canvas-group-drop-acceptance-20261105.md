# 视频工具栏与分组拖放验收（2026-11-05）

## 本轮实现

- 视频选中工具改为直接展开的单层横向胶囊；复用现有 AI 剪辑、截帧、引用续作、适应窗口、全屏、下载及关闭，不展示未接通的高清、复刻等假入口。成片按真实来源隐藏不适用的引用续作。
- 独立节点开始移动时冻结组框，松手时以节点中心与起始组框判断归属；拖出退出，拖入加入，再按完整节点边界扩框。
- 自动组存储 `excluded_members`，防止已拖出的节点被刷新或任务轮询重新吸回。允许单成员组，最后一项移出后去掉空框。任务、素材来源、连线和采购许可不因拖放改变。
- 后端画布合同兼容旧布局，新增排除字段校验；空排除字段归一化，避免旧客户端重复保存产生假修订。
- 规格同步到 `docs/livliv-ui-spec.md`。
