# 短剧画布交互核查与实施建议

日期：2026-11-08。本轮按用户要求仅参考、分析，不修改业务代码，不采购媒体。此前只读投影不等于画布内制作已经完成。

## Oii 实际观察

- Edge 原短剧引导页加载失败；改从正常首页的「短漫剧 → 自由画布」新建独立测试项目。
- 采用自拟《末班灯》四场测试剧本，无私人项目资料，明确只整理剧本与资产清单、不生成媒体。项目：`https://www.oiioii.tv/space/6a07d85e-e0d1-4599-b69e-df1a856c030f`。
- 粘贴后实际出现「识别到你粘贴了长剧本，建议转成txt剧本文本，识别效果更稳定」，提供「直接粘贴／转文件」。没有测出具体触发阈值，不推断其模型识别方法。
- 点击转文件得到TXT附件，上传阶段发送禁用，附件就绪后可发送。
- 发送后画布出现「我的剧本」长文本节点、查看/复制入口及角色/场景/道具选项与「一键提取」。操作要求也被并入原文，这是不宜照搬的部分。
- 对话要求确认画幅、对白语言。选择默认16:9、中文后，页面接续角色设计师，再接续场景设计师。角色清单实际出现陈伯、林夏；工具行展示真实进行状态。尚未以此证明完整分镜、视频或成片链路。
- 后续实际完成角色、场景、道具清单，场景4项、关键道具4项，画布出现剧本到三类资源的连线。最终助手明确说明当前均「未生成」，可后续选风格出图或推进分镜；媒体卡保持无图占位。本次未点击媒体生成或费用确认，未核对积分流水，不把可见余额当作零扣费证据。
- 内容边界也需改进：提取结果为车票新增蓝色圆珠笔、布包新增铜扣等剧本未明确的外观。我们应区分「原文事实／待确认设计建议」，不能把设计扩写伪装成原剧本提取。

## 本地可复用与真实缺口

- `ingestScript` 与 `ingestScriptFile` 最终均复用后端 `ingest_script`；转TXT是输入与原文留存方式，不是新的解析引擎，不保证模型质量自动提高。
- 复用原剧本解析、版本确认、生产快照、资产档案、分镜与按集合成服务。不能把资产文字提取视为已生成图片，也不能让导入/提取按钮包含未展示的媒体采购。
- 现有 `DramaStoryCanvas` 是真实数据投影与阶段入口，仍打开原制作面板；未实现对话上传剧本后在画布内完整制作。
- 风格库已有 `CreationStyleDialog`，平台目录、搜索、个人参考和固定版本引用可复用。短剧风格注册库已有媒介、人物、材质、光线、色彩、负面约束及版本快照，不是只有封面。
- 当前画布Agent工具清单没有独立风格检索工具；这不等于所有入口都无风格信息，但不能把现有选择器当成自主检索已接通。旧风格解析对未知名称回落默认风格，仅可保留历史兼容；新选择不得借此伪造匹配。

## 建议的编排方式

1. 自由创作总监识别用户目标，加载短剧制作技能；手选短剧技能保持该技能。原文、制作要求分开，长文本由输入层提供可拒绝的转TXT建议，不由正则决定剧情和数量。
2. 剧本整理/解析、角色设定、场景设定、道具设定、分镜设计、镜头视频与成片分别是可复用能力。技能负责专业指导和工具选择；项目版本/真实任务状态负责接续依据，不能只依靠对话历史或由模型宣布成功。
3. 文稿保存后创建真实剧本节点。节点底部就地提供「提取角色/场景/道具」，可选范围；执行前说明解析范围和真实费用（如有）。结果创建具备稳定身份的设定卡，再进入可单独确认的资产图片生成。
4. 从已确认剧本与选定资产版本生成按集/场分组的分镜；分镜文本、预演图片、镜头视频分开状态和任务。已完成上游复用，不因续作重新采购。
5. 成片读取固定镜头选版与音轨。确认执行、停止、失败重试和历史作品沿用原服务，切视图不生成第二套任务。

## 风格库长方形卡片

- 卡片整块可点击/键盘打开，左侧大幅三张真实风格封面扇形叠放：左张逆时针、中张直立、右张顺时针。CSS装饰即可，不生成新的封面或重复造弹窗。
- 右侧「选择视觉风格」及当前状态，明确「尚未选择」或实际名称；已选后可更换。三张图只作目录预览，不代表已替用户选中三种风格。
- 点击仍复用 `CreationStyleDialog`。卡片应通过有类型的动作由技能请求，不让模型输出任意HTML/CSS；正文风格由共享UI规范控制。
- 用户已明确风格不重复补问；允许交由助手推荐，不将风格缺失一律当成阻塞。选定后保存真实ID与风格版本快照，作用于下游提示词，不覆盖剧情事实。更换时只说明受影响的未提交方案，不能自动重做已生成资产。

## 开发顺序与门槛

先完成长文本/文件统一导入与剧本节点，再完成画布内提取和资产卡、风格选择闭环，随后接分镜组、镜头视频和成片。独立测试项目逐段验证：原文不丢、角色/场次数量可追溯、同一项目两视图一致、已选风格进入真实生成参数、确认前不采购、刷新不重复建节点或任务。最新实测与旧记录分开，不以只读投影测试代替制作验收。
