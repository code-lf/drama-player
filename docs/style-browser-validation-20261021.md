# 风格大屏弹窗验收（2026-10-21）

## 实现范围

- 复用 UModal、UButton、UInput，非音乐风格统一使用大屏媒体弹窗；音乐风格仍保留真实流派输入能力。
- 最大 1160×780，24px 圆角，桌面七列 3:5 竖卡、16px 间距；小窗口自适应高度，窄屏两列，列表内部滚动。
- 磨砂遮罩和公开封面氛围背景；个人图片不复制到背景。四个范围页签、分类、搜索、关闭均独立于提交生成。
- 上传沿用资料库 style 分类、真实服务端大小配置，支持 JPG/JPEG、PNG、WebP 多选。上传本身不选择、不生成；点击个人风格时固定素材版本，遵守技能图片引用限制。
- 我的收藏调用真实资料库接口，列表使用 files 分组补齐收藏状态；平台风格没有伪造收藏、作者、热度或 New 标记。
- 个人最近使用只在当前组件内记录，换号清空；公开平台风格沿用现有最近使用记录。

## 真实浏览器

使用独立 localhost 电商页，不发送聊天、不调用收费模型。

- 1280×720：弹窗 1160×624，距顶部48px，无窗口裁切。
- 1440×900：弹窗1160×780，左140px、上60px；七列卡片约143.7px宽，间距16px。已截图与参考核对比例、留白、圆角、头部布局和背景磨砂效果。使用本平台真实封面，不复制第三方目录内容。
- 390×844：弹窗358×812，内容宽356px、滚动宽356px，无弹窗整体横向溢出；两列竖卡，分类栏横向滚动。已保存窄屏截图，临时浏览器尺寸已恢复。
- 搜索“日系”仅显示对应风格；3D分类仅显示两项对应目录。
- 点击上传真实打开多选文件选择器，上传自制测试图片成功；我的风格回显。点击个人图片后回到输入框，加入参考图及风格说明，没有自动提交。
- 收藏、我的收藏筛选、重新打开后的收藏回显已实测。
- 平台风格点击后回填“3D 卡通喜剧”。验收后段登录状态失效，关闭登录提示后结束独立验收页；未重新登录，未验收会话失效后的持久化。
- 测试图片 `style-upload-ui-qa.png` 留在个人资料库风格分类并已收藏，未删除用户资料。测试引用曾从草稿移除；末段平台风格选择可能保留在草稿中。
- 未实测收费生成、所有格式分别上传、超大图网络传输及浅色主题。非法格式/超限拦截由组件测试覆盖。
