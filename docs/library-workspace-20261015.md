# 工作台引用、登录与资料库验收记录

## 本次实现

- 我的资产、平台演员、平台音色、文件素材、回收站分组；我的资产仅保留角色、场景、道具、商品、合集。旧分类、文件与版本不迁移、不删除。
- 账号隔离收藏、不可变合集版本、成员固定引用；合集展开时由服务端再次校验权限、成员版本、模型格式与合并后的数量限制。
- 光标跟随 `@` 浮层，中文关键词搜索，左右切分类、上下选条目、回车/Tab 引用、Esc 关闭；请求取消和修订号保护。
- 工具栏资产选择与 `@` 共用兼容查询。删除文字引用标签同步移除对应附件，所有素材修改都会使旧报价失效。
- 游客浏览公开技能及案例，保留纯文字本地草稿；私人接口及收费动作继续鉴权。密码、短信、注册、协议复用独立登录页，微信占位接口不展示。
- 首次引导按账号保存，关闭也只展示一次；默认模式不覆盖显式入口、历史会话和草稿。登录只恢复编辑与报价，不自动生成。
- 短剧新建/修改画幅仅 16:9、9:16，历史画幅不强制改写。
- 平台音频默认仅试听；后台明确标记验证可用后可作为短剧角色声音参考。引用使用原库版本与业务绑定，不复制文件，不调用克隆/TTS。

## 迁移与接口

API 迁移：`20261015_0088_library_workspace`，已在本地升级。新增收藏、合集、合集版本、成员及工作台偏好五张表，不修改历史媒体数据。

- `GET /creation/public-catalog`：游客平台目录，不查询个人技能/收藏，不返回执行指令、资源或私人引用。
- `GET /auth/capabilities`：只返回真实配置的认证入口可用性，不返回凭据。
- `GET|PUT /account/creation-preferences`：账号默认模式、首次引导状态。
- `GET /library/`：兼容旧参数，增加展示分组与收藏筛选。
- `PUT /library/favorites/{kind}/{id}`：幂等收藏/取消收藏。
- `/library/collections`：创建、详情、版本保存、归档/恢复；成员不能嵌套或扩大权限。
- `GET|POST /library/collection-inputs/{id}`：模型兼容预检、固定版本展开。
- `GET /library/reference-search`：服务端兼容搜索，复用原选择器规则。
- `POST /library/role-voice/{project}/{role}`：在现有项目权限下绑定库音频版本。

## 已完成的本地浏览器操作

1. 已登录工作台显示首次模式引导；关闭后刷新不再弹。
2. 输入 `@短剧` 查询真实库素材，左右方向键切分类。
3. 收藏素材后刷新仍保持；验收后恢复原收藏状态。
4. 创建验收合集，追加第二版，并能查看第一版名称与固定成员。
5. 从 `@` 打开合集，确认成员后展开为真实附件和不可拆分标签；未创建生成任务。
6. 连续退格删除引用标签，附件移除、旧报价清空。
7. 合集归档、从回收站恢复成功；验收合集最终重新归档，可通过回收站的“合集”类型恢复，原素材未归档或删除。
8. 独立来源的游客页面可浏览；点击生成只打开深色登录弹窗，取消后文字保留，没有跳登录页。
9. 游客纯文字草稿刷新后恢复；验收后已清理测试文字。
