# 看图对话与会话工具栏自适应

## 本次修改

- 对话存在本人可访问的图片固定版本时，优先保留文字助手已声明的视觉能力；否则使用后台已启用的默认视觉理解模型。无图仍用原文字助手，不修改媒体生成模型。
- 视觉目录按实际 `max_images`／`max_reference_count` 校验完整图片、格式和大小，不截断后继续，不开启被停用的模型或凭据。没有默认视觉模型时明确阻断。
- 图片通过现有结构化模型适配器传输，日志按实际文字／视觉目录冻结采购价；继续由平台承担助手调用，不创建媒体任务或新增普通对话扣费。
- 会话输入框按实际内容宽度使用容器查询：640px 起展开模型、风格、模板文字，820px 起展开参数摘要。长名称省略；窄栏保持图标和 Tooltip，积分与发送同组。
- 仅会话输入框建立新查询容器，不改变首页已有容器尺寸规则。
