# 游客积分与质量提示修复

- 截图的 Sunburst 普通版目录仅支持高质量。旧质量非法时提示正确，但用户改回高后未监听并清除旧错误，导致提示残留。现质量变化即时重新校验，仅清理自己的错误，不吞其他接口错误。
- 之前输入框预算在未登录时直接退出，截图右上为免费注册／登录，因此没有点数。现新增只读公开预算，复用图片 `_quote` 和视频 `_estimate_credits`；正式报价、素材权限及费用确认仍须登录。
- 公开预算拒绝资料库引用、源图片、视频凭证、输入快照、输入顺序与技能执行上下文，拒绝隐藏或停用模型；不读取余额，不返回采购价或执行许可，不调用模型、不新增生成任务。公开预算不初始化或更新默认模板。
- 普通版 Sunburst 缺失比例目录时仅提供现有执行器的方形默认值，不猜测其他比例；非空后台白名单保留。
