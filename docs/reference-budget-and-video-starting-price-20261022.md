# 参考图预算与视频起价改造

## 预算边界

- 用户明确接受近似估算：GPT Image 2每张参考图按原始宽×高÷256向上取整预算输入Token，再乘对应图片输入采购单价；不是官方输入Token公式，也不是保证上界。
- 1024×1024参考图预算4096Token，按44.8元／百万Token估算约0.1835008元。输出多张时每次独立请求重复计算参考输入。缓存按零命中；总人民币预算按已有毛利规则只取整一次。
- 默认规则版本livliv-image-reference-pixels-v1，策略字段image_reference_budget可保存pixels_per_token系数，正式报价快照记录版本、尺寸、系数与分项费用。未自动启用参数报价、迁移价格或改变历史订单。
- 参考图片只接受服务端验证的静态JPG／PNG／WebP上传内容或本人可访问资料库固定版本；损坏图片、未知尺寸及任意外链拒绝报价。参考文档不冒充参考图数量。

## 视频与公开表

- 视频秒价按同模型同规格合并为参考起价；按次区间保留条件，不改后台采购档。
- 有参考视频的示例按输出10秒＋输入2秒计算；正式报价沿用实际素材探测时长。缺失、零及非有限时长拒绝可确认报价。
- 确认卡消费服务端输出与参考计费时长，总积分来自服务端；完成后只核对实际成本，不追加扣费。
- GPT Image 2无参考图示例允许展示，但未启用时明确注明不代表当前扣费金额。

## 验证

- 42项图片预算／档位测试、206项Seedance预算／视频入口测试通过，用户端FAQ及视频摘要5项测试通过；用户端生产构建、后台类型检查通过。
- 直接调用只读公开表得到102条记录、缺价0条、20条参考秒价起；未调用收费生成。
- 应用内用户页能读取，但刷新后点击个人菜单仍未展开，控制台未返回错误；尚未完成真实图片上传报价、确认卡和页面视口验收，不能计为浏览器通过，以上测试不替代实际浏览器结果。
