# 导演制作、MV 与固定图片输入契约

## 本轮边界

保留故事、广告和短剧入口，复用原来的解析报价、项目幂等创建、剧本导入及资产／分镜制作能力。没有新增收费生成接口，没有修改 Logo 导航，没有迁移历史项目。已有未提交修改保留。

### 导演

- 目录 `workflow_type` 由服务端执行器决定：`direct_media`、`direct_or_director`、`director_production`、`mv_production`；文档不能覆盖。
- `director` 显示为短剧制作，保持原编码。文件、正文、想法互斥；原文不调用文字模型，想法才规划。
- `/drama/director-draft` 增加可选 `input_mode=idea|script`；旧客户端缺省沿用原想法规划语义。未传技能的旧专用导演请求按其广告／故事意图兼容，明确传入其他技能不能扩权。
- `/drama/director-draft/file` 复用既有 TXT/DOCX/PDF 提取器及 20MB／20000 字边界，返回同一种预览和流程号。超限拒绝，不截断。
- 预览保存 `input_draft`，用于附件已从编辑器移走后的阶段核价与恢复。脚本改动使报价失效；歌词、范围、歌曲或创意变动需要重新规划。
- 确认脚本前通过 `/creation/runs/{id}/preview` 保存编辑稿，乐观修订防止其他页面覆盖；同文重试幂等。刷新恢复已确认的修改稿，不仅恢复最初模型输出。
- 核价和提交仍调用原解析服务；项目创建继续使用原请求幂等键。只确认解析阶段，不自动购买资产、分镜或成片。

### MV

- 一个已授权音频固定版本，来源互斥；上传或导入新歌曲清理旧歌词、片段和歌曲关联，不清理历史作品。
- 新制作默认整首；兼容旧客户端明确的片段终点。真实时长探测，最多900秒，不静默截30秒。
- `mv_instrumental=true` 明确纯音乐，歌词为空而不是假文本。其他模式先采用用户原文，再读歌曲或本人任务已有歌词／内含逐词结果。
- `/creation/mv/lyrics` 或用户明确开始 MV 制作时可补建内含能力；已有歌词不补建，复用既有音乐任务幂等逻辑，不创建额外付费转写或 AI 写词任务。未接入支持外部音频的转写能力，因此外部缺词明确要求手填，不展示假报价。
- 新快照包含 `range_mode`、`lyrics_source`、`lyrics_status`、`timing_mode`。本轮没有把未校验的时间轴升级为精准同步，始终按估算节奏规划；人工歌词不沿用旧时间轴。
- 歌词仅用于规划视觉剧本，不改写歌词原文；沿用原歌曲主轨、镜头静音和容量不足阻断。历史已绑定快照不重新规划、不自动获取歌词。

### 图片

- 发送冻结原文、参数、素材固定版本及顺序。服务端接收后清理仅属于本次的附件对象；新加／同版本替换对象保留。失败未接收保留草稿。
- `/creation/runs/by-request/{request_id}` 是当前用户范围的只读恢复接口；丢失创建响应不重新创建。已接收但未启动的文字流程提供“继续整理已接收需求”，复用原 advance 幂等保护。
- `reference_previews` 每次授权校验并重新签发，失效明确标识；普通刷新不回填发送附件。
- 新客户端 `extra.references_explicit=true` 发送完整有效集合，包括显式清空。旧客户端同轮缺省可继承父轮固定引用，仍重新检查权限。
- 看图模型必须在启用的模型目录中明确配置 `capability_json.vision=true` 或 `supports_vision=true`，数量／大小来自目录限制；没有标记时明确阻断，不换模型或漏图继续。
- 私有图片由服务端按固定版本读取并内联为多模态图片节点，复用结构化／流式正文及取消状态。审计信封仅保留正文和图片占位，不写 Base64 或图片签名地址。
- 图片／视频生成沿用原 LibraryInputService 有序冻结、绑定、执行时重新解析及供应商适配器。隔离测试检查实际适配器发出的 `image_urls`，并验证版本改变和数量超限会拒绝。
- 二维码原图传输不意味着生成图二维码可扫描，不作此承诺。

## 验收记录

真实浏览器已检查：短剧三种输入控件；粘贴原文进入可编辑预览；修改脚本后读取真实解析报价并停在付费前；MV 无通用图片加号、默认整首、切片段才显示起止；本人歌曲选择后带入真实已有歌词，长歌词框约148px并内部滚动，纯音乐隐藏歌词编辑区；测试图片 Enter 发送后显示在消息中，输入框不再残留；刷新恢复本轮参考，明确移除后刷新仍保持，历史原图不删除。

当前启用的助手模型目录未声明视觉能力，真实页面已显示明确阻断而非声称识别成功。多模态字段和媒体适配器传图使用隔离测试，不冒充真实模型识图验收。额外转写、收费解析、资产生成、镜头生成、最终成片未在真实账号执行。

类型检查：仓库根目录缺少 tsconfig，原 nuxi typecheck 无法直接执行；复用已安装 vue-tsc 与生成配置后发现资产、分镜、通用组件等既有错误，不能报告全仓类型通过。主题检查也仍被既有首页硬编码颜色阻断。本轮问题与既有问题分别记录，不扩改无关模块。

离线回归：134 项相关 API／适配器测试、188 项前端测试通过；其中14项新增 API 测试检查原文预览、并发修订、三种导演入口、歌词、固定版本与实际图片请求。构建通过。完整类型／主题检查仍受上述既有问题阻断；不提交 Git、不部署、不代用户确认协议或费用。
