# MV 歌曲同步交付记录（2026-10-19）

## 已实现

- 保留现有导演制作链；新 MV 使用 `snapshot_version=2`，真实歌曲、片段、歌词确认、画幅与镜头映射冻结，旧项目及旧导出不自动获取歌词、不迁移重算。
- 独立 `mv_lyric_alignments` 表按用户、固定音频版本、对齐模型版本唯一。Suno 复用对应候选曲内含时间轴；其他来源复用阿里文件转写请求适配器的逐词模式，平台承担、不创建用户扣点链。
- 未知提交状态不重提；有任务号只查询，明确失败最多一次显式重试。Beat 只补派安全状态。歌词正文、真实时间戳有序性／范围／完整性校验，错误进入校正，不均分时间、不用写词代替识别。
- 原文与识别结果分离，用户可试听并人工修改。原歌曲版本、时间轴或歌词变化使旧确认失效；剪辑区修改歌词和布局后也需重新确认，排队任务不读取新草稿。
- 成片消费冻结歌词轨，镜头静音、原歌曲为主轨。切点保持用户编辑；容量或时长不符阻断，最终视频按 25fps 校验一帧容差。横排／竖排后期 ASS 叠字，不要求模型生成文字。
- 选歌提示读取实际配置，当前为 MP3/WAV/M4A/OGG、50MiB；音乐生成快捷入口保留 MV 草稿，不自动创建歌曲。“写歌”展示改为“音乐生成”，编码 `song` 保留。
- Logo 悬停展开、菜单内保持、移出延迟收起；保留原导航内容与点击键盘路径。
