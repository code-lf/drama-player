# 技能、ToAPIs 模型与口播优化验收

## 本轮落地

- 快捷技能使用原生 UPopover 悬停预览，封面、公开简介及独立使用按钮；主体只打开四段公开说明，不直接生成。
- 首页、停靠与技能页继续共用同一编辑器及试用链。短剧固定后台制作能力，隐藏技能与模型选择，只显示比例，去掉外边框。
- 新增八个模型，保留 Grok 1.0 并将新任务可选时长设为 6/10 秒。按次型号仅展示别名 `-req`，真实调用编码仍为 `-ext`。
- 模型浮层连续显示图片/视频/音频，Tab 定位及滚动同步不改已选模型。后台维护最多两个主题标识、排序、输出时长档位与人工采购来源。
- 人工采购成本来自本次用户确认的人民币官网报价。60% 毛利率、100 平台积分/元；不复用供应商网站积分。按 Token 型号保留真实采购单价，秒成本仅作预算依据。
- AI口播作为普通平台技能绑定现有视频能力，默认长时型号但不强制 30 秒；使用通用 Markdown、声明式问答、明确参数及费用确认链。阿里专用数字人接口与历史不变。

## 数据与兼容

- API 项目的 `scripts/expand_toapis_catalog.py` 默认预检并回滚，`--apply` 单事务应用。首次新增八个模型；重复执行不增加模型或覆盖人工成本、凭据、排序、用户技能。
- 仅扩展商品图/视频功能白名单，不更换既有默认模型或短剧生产绑定。广告技能发布新版本；不回写历史技能、订单、任务或用户会话。
- 新模型目录、徽章和采购来源复用现有 JSONB，无数据库结构迁移或 MongoDB。
- 报价阶段及适配器共同限制新型号的规格。按次分档以输出秒数匹配，不按输入视频总秒数或输出秒数重复乘价；特殊参考组合不能选恰好 15 秒。
- 人工采购来源锁定时刷新不查询或覆盖该模型；缺价不清零、不下架。解除锁定后保留原币种，兼容人民币及美元采购成本换算。

## 验证结果

- 后端定向回归：146 项通过，涵盖新协议、价格、人工锁定、旧档位兼容及既有技能/创作链。
- 用户端定向回归：35 项通过，包括连续分组导航不选模型、底部分组边界、草稿保留、Tab 示例、详情与试用分离、共享编辑器。
- 用户端 `pnpm build`、管理端 `vue-tsc --noEmit --skipLibCheck` 和生产构建通过。
- 本地数据库只读报价：10/15 秒各 2188 积分，16/30 秒各 4375 积分；按次数量另乘，5/10/15 秒 Fast 均为 875 积分/条。
- 实际浏览器 1280×720：确认快捷技能预览及移入保持、四段详情、模型标识/别名、点击 Tab 定位、手动滚动同步、显式选模及短剧固定入口。公开页面的 AI口播已替代未配置占位。
- 本地 3000/5666/8000 服务及三个 worker 就绪；仍通过一个系统 PowerShell 启动器管理。重启前确认执行、预留、定时任务均为空。
- 三端 `git diff --check` 通过；未提交、未推送、未部署。

## 尚未验证与后续

- 没有调用收费文本/视频/图片生成，没有进行真实口播问答、模型效果、准确口型、失败退款实单或收费端到端验收。协议/费用测试通过不等于供应商实际生成验收。
- 浏览器为游客状态：登录后试用、后台改价持久化没有冒用真实账号验证；现有登录与确认限制保留。1920×1080、1440×900 未实测。
- 全站 `theme:check` 仍被旧首页等既有硬编码样式阻断，本轮未扩大整改。Python 测试保留现有 Pydantic/FastAPI 弃用警告。
- 多条批量确认、两个 15 秒拼接及分钟级轻量制作仅列为后续方向，本轮不开发。完整平台配方保密整改仍独立处理。
