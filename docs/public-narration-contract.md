# 跨技能公开叙事约定

用于当前受控Agent与技能制造机的共享表达层，不替换工具权限、任务状态和报价服务。提示词实际来源为API `app/services/agent_public_narration.py`，本文是产品约定，不将验收文档当运行时提示词读取。

1. 调用前自然说明本次目标，不输出内部变量、接口描述或第三人称工作分析；用户选定的模型、规格可正常展示，不一律视作机密。
2. 真实工具开始/结束保留紧凑状态行，未执行不显示；具体结果紧跟对应成功工具。只读成功可不重复播报，方案交付须有主体、关键处理、约束及当前交付。
3. `creative_summary` 单独承载可持久回放的创意说明，不含确认卡操作、报价就绪或提交引导。模型回复不靠前端正则拆句；旧稿缺该字段不自动改写。
4. 确认、报价失败及重试由真实业务卡按状态呈现。核价成功不作为Agent工具行显示，失败/待核对仍须可见；数字不由模型猜测。
5. 顺序为工具前说明→实际工具状态→真实产出说明→业务确认卡→停止等结论。取消成功不重复显示工具行，避免结论出现在产出前。
6. 用户取消仍使未提交方案停止，隐藏其操作卡与节点；已经生成的文件、历史记录保留，已提交供应商任务不冒充撤销。不得将取消降级解释为只暂停构思且保留授权。
7. 停止后保留新版独立创意正文。旧正文可能混有卡片操作句，无法可靠拆分时隐藏该段而非改写历史；原记录仍保存在服务端。

自动核价移到后端属于独立流程改造；本次叙事调整不宣称已完成该迁移，不改变费用授权与幂等边界。
