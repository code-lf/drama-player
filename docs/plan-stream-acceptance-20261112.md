# 图片方案文字增量验收（2026-11-12）

## 实现与边界

- 沿用现有供应商 SSE、Deep Agents 适配、运行事件和聊天文字组件，没有额外模型调用、新采购能力或新依赖。
- 仅图片 `generate_response` 的严格结构化交付显式开启预览；复用 LangChain `parse_partial_json` 提取创意说明、标题及执行提示词。局部解析仅为展示，不能送入保存、报价、画布成果或任务提交。完整合同仍使用原 Schema／业务校验。
- 不输出原始 JSON、内部思考、工具参数、报价、素材引用或制造机补丁；英文对照待成功后保留原折叠区。仅接收供应商真实 content，最多每 120ms 合并一次快照，不做定时打字。
- 同轮预览稳定身份更新，失败／停止显示未确认内容；已落库方案接替预览，包括完成后再停止，不重复显示两份正文。最终费用确认仍需用户点击，不自动执行。
