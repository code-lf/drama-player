# 模板视频预览与首页优化（2026-10-19）

## 实现及数据范围

- 缩小模板弹窗至最大1160×840，五列小卡片瀑布流，保留模糊公开图片背景。视频可见后加载并静音循环，悬停隐藏标题，离屏暂停；错误时回退图片，浏览器禁止自动播放不伪造播放状态。
- 模板 `preview_video` 保留完整示例，新增 `preview_clip` 专供卡片；迁移0095只加空字段，不批量处理历史视频。上传返回原片、首帧及短预览，保存更换视频时派生最多十秒、720宽静音预览；原片不覆盖。仅接受平台受控地址或仓库固定预设，禁止任意外链抓取。
- 首页视频案例悬停静音播放、移开暂停。MV 的格式大小提示仅在上传音频时显示，“音乐生成”主题色加下划线。首页输入框规格宽增加20%、高度系数0.8421、浅灰边框，悬停／聚焦白灰，长内容及窄屏自适应。
- 已盘点 OSS 的平台站点展示目录：两段原始视频（另两段为本轮生成的预览副本），均为已登记、已关联公开模板的静帧运镜示意。已为 perfume-push、letter-story 生成预览、关联并发布两条案例；沿用已核对的商品细节／人物旧信专业提示词，保留“运镜示意，非模型生成结果”说明。脚本重复执行不新增重复案例。
- 未遍历或公开私人任务、资料库及其他归属未知目录。其他 OSS 视频须先明确展示来源及授权范围，不把桶中可读取误当成可公开。

## 验证记录

- 前端运行与回归209项通过；实际执行业务播放逻辑验证可见性、悬停、静音、暂停及失败状态。
- 用户端 `pnpm build` 通过；构建与浏览器播放验收分别记录，开发期热更新重载不作为播放成功依据。
- API模板、案例和预览19项测试通过；本地真实FFmpeg样本含音轨，验证12秒→10秒、3秒→3秒、预览无音轨、首帧JPEG有效；隔离上传验证完整示例与短预览地址分离，不调用收费模型。后台 `vue-tsc --noEmit --skipLibCheck` 通过。
- 浏览器验证模板两段视频真实 readyState=4、muted=true、paused=false、时长8秒，悬停标题隐藏；首页案例悬停开始播放，移开暂停。MV普通选歌不出现大小说明，切换上传显示配置实际MP3/WAV/M4A/OGG及50MiB，音乐生成链接有主题色和下划线。

- 本地API加载新增迁移和预览接口；未提交Git、未部署服务器、未触发收费生成。案例发布和OSS预览上传是本次用户明确要求的数据变更，不冒称“没有数据修改”。
