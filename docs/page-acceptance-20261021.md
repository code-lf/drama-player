## 发现的问题

### QA-01：切换 Sunburst 后保留不支持的质量参数（P1）

- 路径：自由创作 → 当前为 Grok Video 1.0 → 模型列表 → 选择 `gpt-image-2.5-sunburst` → 参数。
- 实际：提示“当前模型不支持已保存的图片质量，请重新选择质量后预估”；底部仍显示“快速”，参数面板却仅提供“精细”。手动点击精细后底部质量才更新。
- 同时出现比例为空、摘要以“· 1K”开头、六个比例全部禁用的状态。
- 影响：主动选择新模型后仍进入无效规格状态，参数展示不一致。未继续发送，因此没有把此结果表述为真实生成失败。
- 建议：区分恢复历史草稿与用户主动切换模型，主动切换应归一到该模型真实支持的默认质量；若模型不提供比例选择，应隐藏比例区和空分隔符，否则补齐已验证的比例能力映射。
- 排查入口：`features/creation/components/CreationComposer.vue` 的 `chooseModel`；`features/creation/useCreationWorkspace.ts` 的质量检查与比例映射。
- 证据：`../.codex-runtime/qa-sunburst-invalid.png`。

### QA-02：1280×720 下模型浮层顶部被裁切（P2）

- 路径：自由创作，输入框位于当前视口较上方时打开模型列表。
- 实际：浮层矩形为 top=-59、height=425；标题区域 top=-46、bottom=-21，“选择模型”和关闭按钮在视口之外，分类 Tab 也贴近上沿。
- 1920×1080 下同类浮层 top=30，未出现该裁切。
- 建议：根据锚点上下可用空间限制浮层与内部列表高度，必要时换侧，保证标题、关闭按钮和分类区始终可见；不能只按整个视口高度设置最大高度。
- 排查入口：`CreationComposer.vue` 的 `UPopover` 与 `creation-model-list` 高度。
- 证据：`../.codex-runtime/qa-model-clipped-1280.png`。

### QA-03：首页底部试用滚动变化（特定操作待复核，不作为普遍阻断）

- 用户后续提供真实操作截图，确认其鼠标点击“试一试”后能在底部正常展开。保留下述自动化特定操作的观察记录，但不再把它概括为首页试用普遍失败；本轮不修改停靠业务逻辑。

- 路径：电商首页滚到底部，已出现一行停靠输入框 → 悬停技能卡片 → 触发“试一试”。
- 实际：广告短片试用成功后回到顶部大输入框；AI口播复核时，鼠标触发还出现了滚动位置改变但未切换技能的情况，随后键盘 Enter 可选中，但仍回到顶部。
- 记录：底部主滚动容器 scrollTop=611；鼠标复核后变成451；键盘成功选用后为0。
- 影响：不符合“在当前卡片浏览位置把底部输入框直接展开”的要求；鼠标点击受滚动／焦点变化影响，需专项复测。
- 技能中心同类流程正常，不能以技能中心通过代替首页通过。
- 建议：在按钮获得焦点／浮层关闭之前保存停靠状态与滚动位置；展开与聚焦使用不滚动策略，并检查选择技能后的响应式更新是否改变停靠阈值。
- 排查入口：`CreationStudio.vue` 的 `useHomeSkill`、`finishHomeSkillSelection`、`expandHomeComposer`、`trackHomeDock`。
- 证据：`../.codex-runtime/qa-home-before-try.png`、`../.codex-runtime/qa-home-after-try.png`。
