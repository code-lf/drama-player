## 3. 提示词与示例图片的实际行为

- bestPractice保持段落与场景内容，仅把`{{内容}}`转换为本站可编辑字段；试用后成为用户草稿，参与助手整理和最终执行提示词，不等于直接把公开示例当系统指令。
- description、applicableScenarios、howToUse、outputDescription没有逐字全量恢复；本站说明主要为改写版本。不能说这些字段已经完整迁移。
- 试一试使用example_refs展示示例图，用户可以替换或移除；不写个人素材库，不自动发送、执行或扣费。固定执行references仍独立。
- 后台下架示例后不能继续作为有效输入；示例数量超出当前模型限制时沿原素材校验明确拒绝，不静默截断。
- 继承风格在示例明确商业摄影等要求时清除，手动选择的冲突风格需确认；不悄悄继续套卡通风格。
- 所有来源媒体保留内部来源；封面与预览是临时展示，示例图单独登记来源，不自动声明商业授权。
